# Vision Studio 2.8.0

YOLO YAML 的 One Dark Pro 风格代码视图、按模型能力显示入口、数据集启动恢复偏好和更新后的使用指南。

- YAML 深色配色、行号、当前行、注释及括号高亮；搜索、复制、安全另存、全局模型缓存保持。
- ONNX 和无架构元信息的模型隐藏 YAML 入口，切换模型清除旧视图。
- 「更多 → 启动时恢复上次数据集」默认开启，可关闭下次启动恢复，路径记录保留，不自动推理。
- 使用指南按实际工作流重写，侧栏位于「更多」正上方。

保持 C++17／Qt 6.8.3、Fluent 深色、现有 CPU／NVIDIA GPU 后端及用户数据，无新增运行依赖。Debian 版本为 `2.8.0-1`，安装到 `/opt/VisionStudio`。
