# Vision Studio 2.9.0

完善模型评估与实验报告：九类诊断图表、六类场景分析、历史预测快照独立重分析，以及 PT 批量推理。

- 评估界面拆分五个内层页，展示 AP75、Wilson 95% 区间、FPPI、整图漏检和两种不同口径的混淆矩阵。
- 完整场景分组 AP、工作点与错例；未审核场景明确未知，子集／中断不冒充整集结果。
- PNG／SVG／PDF、可选 DPI、PR／AP／场景数值表及 LaTeX 表格行。
- 可导入既有脚本完整评估报告，原始类别不重编号，配置未知时禁止自动采用。
- 无原模型／数据集也可从已校验快照生成新报告，原报告保留；叠加预览仍需原图。
- PT 支持真实 batch，ONNX／TorchScript 诚实记录单张执行；可调候选下限、每图框数和 PT CPU 线程。

保留 C++17／Qt 6.8.3、Fluent 深色界面、现有 CPU／NVIDIA GPU 后端及用户数据，无新增运行依赖。Debian 版本为 `2.9.0-1`，安装到 `/opt/VisionStudio`。Windows 已发布版仍为 2.1.0。
