# Vision Studio 2.7.0

本版把 YOLO 架构配置接入模型显示，并恢复更直接的预览拖入工作流。保留 C++17／Qt 6.8.3、Fluent 深色界面及现有 CPU／NVIDIA GPU 后端，无新增运行依赖。

- 模型显示新增「YOLO YAML」，与结构图、层级树和参数表共用全局模型及解析缓存。真实读取模型保存的架构字典，展示 `# [from, repeats, module, args]`、backbone／head、缩放与 anchors；缺少元数据时明确提示，不按文件名猜测网络。
- 深色只读语法高亮、搜索定位、复制和安全另存 YAML／YML。生成的是保存架构字典的等价配置，原始注释及排版不可恢复；不是训练检查点还原，也不保证任意自定义训练工程可复现。另存拒绝覆盖源模型、已有文件及符号链接。
- 图像预览支持直接拖入数据集文件夹、YAML／YML、视频，以及单张／多张图片。图片按拖入顺序去重并后台检查、分片建队列、按需解码，不新增密集输入按钮。
- 已有数据集时弹出深色三选框：替换整个数据集、临时加入或取消，默认取消。临时图片只参与检测、回看与导出，不写原数据集，不伪造 GT，不进入评估统计，不记录到启动恢复 JSON；再次启动仍恢复此前成功载入的数据集。
- 临时追加时，数据集原有结果、报告和缓存保留；三种评估范围仅选择原数据集成员。选中临时图片后「当前／向后」评估显示行内提示，整集合评估仍仅处理原集合。运行中拒绝改变输入，追加中停止撤销本次追加。

完整一次 22 套回归通过（396 项 Qt、101 项 Python，零失败／跳过），生产输入及二进制前后 SHA256 一致。最终包 CPU／CUDA、转换、公开四图六用例／三组同权重比较／91 阈值、隔离安装／运行／卸载和完整对应源码均已验收。三模型 YAML 静态比对与最终包 12 阶段拖入工作流另行通过；临时图片未污染评估或路径记录。私人 Val 1223 张仅做只读预检，16667 个文件未变，不作为精度成绩。实际结果与限制见[同版证据](https://github.com/misaka-ning/vision-studio/blob/v2.7.0/docs/releases/evidence/2.7.0/README.md)。未执行检查不标为通过。原始验收资料完整保留在本地；因自动审批限制，仓库公开去标识结果、原件校验承诺与已人工核对的原样截图，不将摘要冒充原始日志或作为原始 finalizer 输入。

正式附件保持三项：`vision-studio_2.7.0-1_amd64.deb`、`vision-studio-2.7.0-complete-source.tar.xz`、`SHA256SUMS`。安装到 `/opt/VisionStudio`，升级前结束任务并退出旧程序，个人设置、模型、记录、录像、评估报告与独立 GPU 环境保留。Windows、物理摄像头及任意自定义 YOLO 架构兼容性未列为本轮已验收项目。
