# Vision Studio 2.0.0-beta.1

本版提供 Fluent 风格的桌面界面更新，保留 1.6.0 的功能和操作逻辑。已在 Ubuntu 22.04 amd64、Qt 6.8.3、NVIDIA RTX 4060 上完成最终安装包验收。

本版范围是桌面 UI 调整，推理后端、预处理和用户数据约定沿用 1.6.0：C++ OpenCV ONNX CPU、可选 C++ ONNX Runtime CUDA、常驻 Python PT、全局模型选择、Netron 三视图缓存、灰度 C1／C3、左右目、标注录制和 PNG／JSON／CSV 导出继续保留。完整变更见 [更新日志](https://github.com/misaka-ning/vision-studio/blob/v2.0.0-beta.1/CHANGELOG.md)。

## 界面变化

- 中性深色窗口、卡片与输入层；蓝色 `#60CDFF` 操作／选中／焦点，清晰的正文和辅助文字亮度。
- 4 px 控件、8 px 卡片圆角；212 px 侧栏和 3 px 导航选中条。
- 图片、批量、视频、摄像头入口横向放在顶部；设备、GPU 编号和提示位于第二行。
- 左配置、中画布／队列、右结果表；Netron 结构图、层级树和参数表统一深色视觉。

保留现有原生 Qt 类、信号连接与键盘行为。[Fluent-Qt](https://github.com/calvinhxx/Fluent-Qt) v1.9.2 作为视觉参考，MIT 原通知与来源位于 `packaging/licenses/fluent-qt-design-reference/`；不引入其库、字体、微软图标或 Gallery 资产。

## 预发布与文件

应用版本／发行目录为 `2.0.0-beta.1`，带说明的 Git 标签为 `v2.0.0-beta.1`。CMake 数字版本为 `2.0.0`，完整版本由 `VISION_STUDIO_APP_VERSION` 给出。Debian 使用 `2.0.0~beta.1-1`，保证排序在同版正式包之前。

内部 Debian 版本含 `~`，公开 DEB 文件名采用安全的 `-beta.1`；APT／DPKG 读取内部 Control 排序。安装包内容、完整源码与 `SHA256SUMS` 始终按相同公开文件名对应。

GitHub Release 必须标记 Pre-release，并明确 `latest=false`，当前正式版 Latest 保留。发布后只提供三个手动附件：

- `vision-studio_2.0.0-beta.1-1_amd64.deb`
- `vision-studio-2.0.0-beta.1-complete-source.tar.xz`
- `SHA256SUMS`

完整源码包内包含应用源码拆分归档、源码清单、内部校验、15 份原始上游源码与通知。GitHub 自动提供的 ZIP／tar.gz 不能替代完整对应源码包。

## 验收与保留

beta 使用和正式版本相同的 QA 门禁。发布前完成 UI／模型显示、CPU／GPU、灰度 C1／C3、左右目与录制回归，最终 DEB 的普通用户运行、隔离安装／卸载、包内 CUDA／CPU 和源码验收；报告绑定本版最终 SHA256，保存在仓库 `docs/releases/evidence/2.0.0-beta.1` 并链接原始日志。

8 组 CTest 通过，最终布局 UI 回归再次通过；GPU 后端 10 项、录像 14 项均 0 失败、0 跳过。新 ONNX 轨迹记录 364 个实际 CUDA 节点；灰度 C1／C3、三类 PT、取消恢复和右目灰度录像通过。最终 DEB 已完成普通用户 CPU 与模型三视图缓存、断网隔离安装／卸载、包内 ONNX／PT CUDA／CPU 四轮检查。20 张真实截图完成视觉检查，最小 1260 × 820 窗口画布完整。发布／保留、元数据、GPU 环境安全共 80 项测试通过；14 项静态审计确认操作与参数保持。完整报告和原始日志见 [同版验收证据](https://github.com/misaka-ning/vision-studio/tree/v2.0.0-beta.1/docs/releases/evidence/2.0.0-beta.1)。最终源码伴随包校验报告在归档完成后加入该目录，避免报告自引用；应用和构建输入保持冻结。物理摄像头未实测。

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.0.0-beta.1-1_amd64.deb
vision-studio
```

默认 `prune` 只处理正式版本，beta 不自动删除或挤掉正式备份。预发布期间保留当前正式版用于回退；如按最新两版要求释放其他旧副本空间，须逐版精确核对已公开远端文件与 SHA256 后清理。标签、已发布核心资产和原始归档不可改写。

新代码保持 AGPL-3.0-only，Qt／Netron／CUDA 等组件保留原始许可。安装目标为 Ubuntu 22.04 LTS amd64，目录为 `/opt/VisionStudio`；用户设置、模型、运行记录和录像保留。
