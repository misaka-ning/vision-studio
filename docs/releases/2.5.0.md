# Vision Studio 2.5.0

本版改进数据集导入、大队列响应和工作区布局，继续使用 C++17／Qt 6.8.3、Fluent 深色界面与既有 CPU／NVIDIA GPU 后端，无新增运行依赖。验收范围、实测结果和限制以同版证据报告为准。

## 主要变化

- 数据集文件夹和 YAML 共用一个选择器，不再通过箭头先选导入类型。单击文件夹后确认导入，双击仍可继续浏览；现有 YAML／YML 文件可直接导入。非法路径与类型显示行内提示，不增加确认弹窗；根目录配置解析、失效路径只读迁移和失败后重试保持既有规则。
- 大队列按 GUI 事件循环分片建立，缩略图按可见项及邻近范围后台解码，选中原图及缓存叠加异步加载。快速换图、切换颜色、清空或更换来源后丢弃过期回调，避免旧图覆盖新选择。队列顺序、三种范围、GT、结果回看和所选图片导出继续保留，无固定 50 张上限。
- 数据集设置改为锚定按钮的深色悬浮卡片，类别映射、扫描参数与可选审核文件不占工作台布局。再次点击按钮、点击外部、按 Esc 或关闭按钮均可收起；调整窗口与切页安全关闭，忙时锁定，完整校验错误可滚动和复制。
- 工作台「图像预览」「评估与阈值」各占完整工作区：检测页保留参数、画布、队列和目标表，评估页使用完整空间查看指标、曲线、错例与报告。切页只改变查看位置，不改变任务模式或配置、不清空缓存、不重复推理；点击对应开始操作才执行检测或评估。
- 保留全局模型、灰度 C1／C3、左右目视频／摄像头、录制、模型显示、转换、持久评估及已采用配置。个人设置、模型、运行记录、录像和历史报告不删除；已公开标签与旧发行文件不改写。

## 实际验收

[同版证据目录](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/README.md)保存本轮真实日志、JUnit、模型与安装包检查。有效回归为 **18 套、305 项 Qt、101 项 Python**，无剩余失败或跳过。结果由完整执行中通过的 17 套，加上异步回看等待修正后相同 38 项 scope CPU 复验组成，**不是一次完整 18 套全部通过**。初轮 scope 的 14 通过／24 失败及所有原始证据保留；修正只插入 35 行等待和额外真实像素断言，每条旧源码行、所有原断言与模型 fixture 均保留，仅该测试源码和原生测试程序改变，生产应用及其余快照输入哈希不变。详见 [ctest-qa.json](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/ctest-qa.json)。

[UI／队列七项](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/ui-queue-qa.json)与 [GPU 七项](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/gpu-qa.json)门禁均通过。真实选择器、悬浮卡片、长错误、完整工作区切页及四组 1260／1380 宽 CPU／CUDA 布局有具名原生检查。2000 张标准 YOLO 合成小图实测在部分填充 96 项时停止，停止调用 3ms，初始 6 张缩略图、136 次心跳、最大间隔 66ms，快速选图和清空后未接受过期结果；这些仅是本次调度测试观察，不是其他机器／大图的性能保证，也不是单独的安装包专项 UI 执行。

最终 DEB 的只读 CPU／CUDA、转换、命名空间实际安装／运行／卸载、文件夹迁移、对应源码及私人数据只读预检均通过。公开 COCO8 四张 Val 图片完成 **六个真实模型用例、三组同权重后端比较**，CUDA 评估 profile 记录 910 次节点事件。私人 Val 1223 张（813 张有框、410 张空标签）仅做预检，整个数据根 16667 个文件前后哈希不变，未做准确率推理。详见[包内评估矩阵](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/packaged-evaluation-qa.json)、[隔离安装](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/install-qa.json)与[源码核验](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/source-bundle-qa.json)。

公开标注集证明管线、指标与后端一致性，不是足球专项精度或部署性能基准；COCO ID32 为 sports ball。评估仍只针对所选目标类 AP，不提供多类总体 mAP、训练、分类评估或视频在线 mAP。Windows 2.5.0 与物理摄像头不列为本版已验收项目。

## 安装与对应源码

发行标签使用 `v2.5.0`，Debian 包版本为 `2.5.0-1`，默认安装到 `/opt/VisionStudio`。最终文件已生成并通过本版验收；Linux Release 保持三个手动附件：

- `vision-studio_2.5.0-1_amd64.deb`
- `vision-studio-2.5.0-complete-source.tar.xz`
- `SHA256SUMS`

文件大小与 SHA256 见 [final-assets.json](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/final-assets.json)：DEB 387201252 字节，完整源码 883232864 字节，`SHA256SUMS` 207 字节。发布后先校验再安装：

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.5.0-1_amd64.deb
```

升级前结束检测、评估、录像与模型转换，导出需要长期保留的临时结果并退出旧程序。保留个人资料与已准备 GPU 环境。完整源码包提供实际应用源码及需交付的原始上游源码、来源、许可与校验；GitHub 自动源码 ZIP／TAR 不代替完整对应源码包。

宿主安装与发布后的远端核验、保留两版清理分别记录在同版证据目录，不以隔离安装代替宿主安装。只有远端标签、公开状态、三个附件大小与 SHA256 全部核验成功后才精确清理旧副本。既有 Linux 核心附件、Windows 2.1.0 补充包与历史证据保持原样。

本版已公开且远端核验、精确保留两版均已完成，见[独立发布与清理凭证](https://github.com/misaka-ning/vision-studio/blob/main/docs/releases/evidence/2.5.0/publication.md)。宿主升级仍待系统管理员认证，不以隔离安装代替。
