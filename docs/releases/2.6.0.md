# Vision Studio 2.6.0

本版记住最近一次完整成功载入的 YOLO 数据集，普通启动即可后台恢复原文件夹／YAML、Train／Val／Test 及可选审核文件。沿用 C++17／Qt 6.8.3、Fluent 深色界面和既有后端，无新增运行依赖。

- 独立记录在用户数据目录的 `dataset-session.json`，不写安装树或数据集，不包含模型／图片／标签内容。
- 使用 Qt `QSaveFile` 同目录临时写入并原子替换，禁用原地截断回退；读单一文件句柄，校验版本、字段和大小。失败、停止或未完整载入不覆盖旧记录。
- 启动恢复复用后台预检查、分片队列和懒加载，只恢复输入与 GT；不会自动开始检测／评估或混入旧预测。手动选择优先，异常记录和失效路径行内提示，缺记录时静默正常启动。
- 清空队列、视频／摄像头和历史报告不隐式抹除最后成功来源。可退出后删除该 JSON 忘记数据集，源文件保持不变。

「查看错例」同时修复：点击即筛出当前阈值下全部 FP／FN 错图，按原队列顺序去重，支持上一张／下一张及当前序号。评估与预览均显示错图、本次已评估和集合总数；负图误报纳入，子集／中断只统计完成部分。阈值与筛选在后台更新，不重新推理、不修改原报告；零错与缓存校验失败分别显示。

本版一次完整执行 20 套回归，343 项 Qt、101 项 Python 全部通过，零失败／跳过；生产输入和二进制前后哈希一致。最终包的 CPU／CUDA、转换、公开四图评估六用例／三组同权重比较／91 阈值、隔离安装／运行／卸载及对应源码均已验收。目录和 YAML 各完成真实评估写记录、退出后另一个进程恢复，队列／GT／首图一致且无自动推理或新报告。私人 Val 1223 张仅做只读预检，16667 个文件未变，不能作为模型精度成绩。

YOLO YAML 模型展示另已完成可行性调研，尚未包含在本版应用中；实现边界见[设计说明](https://github.com/misaka-ning/vision-studio/blob/main/docs/YOLO模型YAML展示设计.md)。

本版实际测试、最终包与发布状态以[同版证据](https://github.com/misaka-ning/vision-studio/blob/v2.6.0/docs/releases/evidence/2.6.0/README.md)为准，不以旧版验收代替。

正式交付仍为 `vision-studio_2.6.0-1_amd64.deb`、`vision-studio-2.6.0-complete-source.tar.xz` 和 `SHA256SUMS` 三个手动附件。默认安装到 `/opt/VisionStudio`，用户资料和已准备的 GPU 环境保留。升级前结束任务并退出旧程序；Windows 和物理摄像头未列为本版已验收项目。

发布及远端校验完成，已保留本地 2.6.0／2.5.0。标签与核心资产未改写；[发布后凭证](https://github.com/misaka-ning/vision-studio/blob/main/docs/releases/evidence/2.6.0/post-publication/README.md)另随主线维护。
