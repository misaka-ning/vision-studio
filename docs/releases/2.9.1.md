# Vision Studio 2.9.1

优化评估中的阈值选择：推荐、曲线、指标和明细在同一页完成，沿用 C++17／Qt 6.8.3 与 Fluent 深色界面。

- 默认「阈值调优」采用左侧曲线、右侧推荐决策、下方可调阈值表；选择推荐、点击曲线、输入阈值或选中表格行保持联动。
- 当前点与推荐点分别标识；错例入口复用现有图像预览和返回流程，只有明确「采用到检测」才修改工作台配置。
- 「能力诊断」保留 AP、扩展指标与深入图表；「场景分析」保留真实已保存的统计阈值；「报告管理」集中导入、导出和快照重分析。
- 紧凑报告与任务信息，评估算法、报告格式、后端和运行依赖保持；设置、模型、录像和历史报告继续保留。

实际执行结果与限制见[同版验收证据](https://github.com/misaka-ning/vision-studio/blob/v2.9.1/docs/releases/evidence/2.9.1/README.md)。未执行项目不写成通过，不以旧版结果替代本版最终包验收。Windows 已发布版仍为 2.1.0。

正式版使用 `v2.9.1`、Debian `2.9.1-1`，默认安装 `/opt/VisionStudio`。三个手动附件为 DEB、完整对应源码包和 SHA256SUMS；远端核验成功后保留本地 2.9.1／2.9.0。冻结标签及历史资产保持。
