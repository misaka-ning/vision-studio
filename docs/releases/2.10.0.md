# Vision Studio 2.10.0

模型库现在支持从文件管理器直接拖入模型，单个或批量导入都可以。

- 支持本地 `.onnx`、`.pt`、`.torchscript`；页面、子控件和列表可接收，导入按钮也支持多选。
- 整批校验通过后按输入顺序去重并追加，已有条目保留名称、备注、排序和关联配置。**去重后最后一项**全局选用，同步到检测工作台、模型显示与转换页。
- 非法混合输入整批拒绝并行内提示，任务忙时不更换模型；原文件不复制到应用目录、不移动或改名，原有内部排序与右键操作保持。
- 保留 C++17／Qt 6.8.3、Fluent 深色界面和既有 CPU／NVIDIA GPU 后端，无新增运行依赖。

完整执行 26 套回归：436 项 Qt、159 项 Python，零失败／跳过。最终只读 DEB 的模型库专项 21 项真实断言通过，覆盖 ONNX／PT／TorchScript 拖入、解析、缓存及当前全局 ONNX CPU 检测与导出。对应源码与隔离安装已验收。

完整范围及原件承诺见[同版证据](https://github.com/misaka-ning/vision-studio/blob/v2.10.0/docs/releases/evidence/2.10.0/README.md)。持久化恢复另以原生窗口重建回归记录为准，包专项 `restart_executed=false`；检查不作为精度或速度基准。
