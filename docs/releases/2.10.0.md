# Vision Studio 2.10.0

模型库支持直接从文件管理器拖入模型，批量导入与原有排序、模型管理及全局选用连贯使用。

- 拖入一个或多个本地 `.onnx`、`.pt`、`.torchscript` 文件，也可使用导入按钮多选；两种入口共用校验。
- 按输入顺序追加并按规范路径去重，复用已有条目及其名称、备注、顺序和关联配置，最后一项全局选用；不搬动原文件。
- 非法混合输入整批拒绝并显示原因，忙时不更换模型。保留列表内部拖动排序、右键菜单及重启持久化。
- 沿用 C++17／Qt 6.8.3、Fluent 深色界面及 CPU／NVIDIA GPU 后端，不增加运行依赖。

本版实际测试、最终包、安装和交付结果见[同版证据](https://github.com/misaka-ning/vision-studio/blob/v2.10.0/docs/releases/evidence/2.10.0/README.md)。目前仍在实现与验收，不把未执行检查声明为通过。

Ubuntu 22.04 amd64；Debian `2.10.0-1`；安装到 `/opt/VisionStudio`。正式发布附件为 DEB、`vision-studio-2.10.0-complete-source.tar.xz` 和 `SHA256SUMS`。Windows 已发布版仍为 2.9.1，本次不预先声明 Windows 2.10.0 安装包已验收。
