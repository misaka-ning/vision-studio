# Vision Studio 2.10.1

**状态：发行验收进行中，尚未发布。** 本文记录待交付版本的变化与验收边界；不表示安装包、对应源码或 GitHub Release 已经完成。当前已发布的 Linux 版本仍为 2.10.0，Windows 版本仍为 2.9.1。

## 本次变化

本版主要整理内部架构，保留现有 Fluent 深色界面与操作流程。MainWindow 负责装配、导航和交互适配；模型、输入、检测、评估、配置、结果保存、录像与 GPU 环境由独立控制器和服务管理。页面展示只读快照并发送操作意图，不维护另一份可独立修改的业务状态。详细边界见[应用架构](../architecture/应用架构.md)。

- 模型库、检测工作台、模型显示与转换页继续使用同一全局模型；名称、备注、排序和原有结构缓存保持。
- 数据集导入、临时图片、三种检测范围、停止回看、类别筛选、历史报告及阈值采用继续遵循既有规则。后台回调以来源身份和 generation 拒绝过期结果，结果交付继续释放每个图像 ticket。
- 窗口关闭统一进入异步收尾：停止新的调度，等待已接受的图像保存、流输入最后一帧、录像、模型结构辅助进程、转换清理及其他在途任务结束，再关闭窗口。GUI 事件循环继续工作；当前 ONNX CPU forward 仍需到原停止边界。
- 修复运行环境准备成功后排队的旧重试未被取消的问题，窗口关闭后不再启动该重试，后续窗口仍可使用共享准备服务。
- 修复转换成功通知与紧接取消之间的输出回滚竞态。真实导出核验、无覆盖发布和本轮临时目录清理完成后，最终成功通知开始即保留已完成文件；通知期间被取消也不删除该文件。此前失败仍只清理本轮身份一致的输出，保留原模型和其他用户文件。

保留 C++17／Qt 6.8.3、既有配置和数据格式，无新增运行依赖。ONNX CPU 仍为 C++ OpenCV DNN，ONNX CUDA 仍为 C++ ONNX Runtime CUDA，PT／TorchScript 仍使用常驻本地 Python／PyTorch；模型协议、预处理、灰度 C1／C3、左右目约定、推理和评估算法保持。本版不宣称识别精度或推理速度提升。

## 计划交付

Linux 目标为 Ubuntu 22.04 amd64，应用版本 `2.10.1`，Debian Control Version 计划为 `2.10.1-1`，默认安装位置 `/opt/VisionStudio`。正式 Release 保持三个手动附件：

1. `vision-studio_2.10.1-1_amd64.deb`
2. `vision-studio-2.10.1-complete-source.tar.xz`
3. `SHA256SUMS`

文件尚待构建和验收，本文不预填下载完成状态或校验值。GitHub 自动生成的 Source code ZIP／tar.gz 不能替代完整对应源码包；QA 和原始日志保存在同版仓库证据中，不额外上传零散附件。

升级保留个人设置、模型列表、数据集路径记录、运行记录、录像、评估报告与已准备环境。安装前结束任务、导出需要永久保留的临时结果并退出旧程序；窗口会在已接受任务收尾后关闭。普通图像缓存不跨重启，持久评估报告另行保存。

本版源码标签与历史发行不可覆盖或移动。最终证据提交若晚于生产输入提交，必须按[版本管理](../版本管理.md)核验生产输入一致及对应源码追溯关系，不能用较新的文档提交冒充已经重建的安装包。
