# Vision Studio 2.9.1 Windows 补充发行

Windows 功能同步到 2.9.1，提供两种安装方式：

- **离线包**：包含完整 CPU 环境，安装后导入自己的模型和输入即可使用 PT、ONNX、转换、模型视图及评估。
- **在线包**：先提供 ONNX 本地推理；PT、转换、Netron 视图及数据集评估首次使用时准备共用运行环境。显示体积与进度，支持取消、重试和 SHA256 校验，准备成功后可离线使用。

两个包均不安装源码归档、历史文档、验收材料、示例模型或测试图片，保留界面资源、运行脚本和许可证。在线包减少首次下载量，使用全部功能后的运行环境占用接近离线包。GPU 环境继续单独按需准备，不修改显卡驱动。

默认安装到 `C:\Users\<用户名>\VisionStudio`，可以选择其他专用目录。配置、记录、录像、转换结果、评估报告和运行环境缓存在用户数据目录，升级及卸载保留个人资料。

本轮补齐新版评估与报告脚本，修复 Windows 路径格式、YAML 新文件另存、TorchScript 中文路径以及数据集记录替换的文件操作差异。安装器只清理旧安装清单中未修改的过期文件，并保留用户新增或修改的旧文件。

Windows 交付为两个 EXE、CPU 运行 ZIP、独立 Windows 源码 ZIP 和 `SHA256SUMS-windows-x64`，普通使用只需选择一个 EXE。源码与 Windows FFmpeg 对应源码单独下载，共享上游来源沿用同页冻结的完整源码包，安装器不会下载这些材料。

实际大小、验收状态、测试系统和限制见[Windows 验收证据](evidence/2.9.1/windows/README.md)。原 Linux DEB、完整源码包、校验清单和 `v2.9.1` 标签保持冻结；Windows 源码使用独立标签 `windows/2.9.1-1`。
