# Vision Studio 1.1.0 验收资料

此目录保存该版本原始报告、日志、截图及校验资料；文件内容沿用当时的交付记录。部分历史报告含本地验收路径，以执行内容和结果为准。

[发行下载](https://github.com/misaka-ning/vision-studio/releases/tag/v1.1.0)仅展示 DEB、完整对应源码与 SHA256SUMS 三个手动附件。`PUBLIC-ASSETS.json` 记录这三个文件；`ORIGINAL-RELEASE-ASSETS.json` 保存首次上传时的完整附件清单，供历史追溯。

应用源码拆分包与第三方对应源码、SOURCE-INVENTORY.json、SOURCE-SHA256SUMS 可在完整对应源码包内获取。
