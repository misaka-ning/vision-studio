## 最终包的实际验证

最终只读DEB已完成CPU／CUDA、ONNX／PT／TorchScript、转换、公开COCO8四图的六用例和三组同权重比较／91阈值、数据集与拖入、模型YAML、独立进程启动恢复，以及隔离安装／运行／卸载与完整对应源码验收。三进程启动偏好检查保留关闭恢复的原始success=false／exit1，将空队列且未自动推理归为预期拒绝；开启与缺少设置键分别实际恢复。原件另有[校验承诺](startup-original-commitments.json)。

[新增评估与导入门禁](reports/evaluation-features-qa.json)对应最终包的CPU和CUDA各四个实际用例，覆盖batch=1／3及有序尾批、未审核／合成审核分组、独立新匹配IoU。九类图各自生成并重开PNG／SVG／PDF，专用CSV与LaTeX数值对已保存报告核验。移动仅供QA使用的模型／数据副本与原报告目录后，迁移快照仍可离线重新分析，并与重新推理报告的全部91点相符；原始数据和报告字节保持。场景审核标记是明确的合成测试夹具，不冒充真实困难场景评测。

历史脚本报告另由最终包内Python及导入helper实际执行，严格检查四个快照、逐样本缓存、原始类别、来源参数、范围、输出图表及未知配置保护；不知道的计时、设备与预处理不补造，报告和请求均禁止自动采用未知配置。私人历史记录只用于只读兼容验证，未公开其路径、图像、指标或运行环境；不作为本版准确率或速度基准。原始报告、子进程输出、缓存与文件哈希仅保留本地，公开的是批准布尔结果和原件整体SHA256。
