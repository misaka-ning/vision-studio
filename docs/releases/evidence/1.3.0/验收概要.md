# Vision Studio 1.3.0 验收概要

发行平台为 Ubuntu 22.04 amd64，默认安装到 `/opt/VisionStudio`。维护者为 misaka_ning <1468549029@qq.com>，应用源码按 AGPL-3.0-only 发布。

本版增加「录制视频」与末尾的「更多」，保留原四页；运行示例与手动导出移至「更多」。灰度底图与实际模型输入一致，切回彩色恢复原色并清除旧预测。视频 / 摄像头检测可开始和结束录制，保存当前完整画面或所选单目及标注，列表支持预览、播放与导出。

## 已执行验证

- 四套 CTest 全部通过：Core 34、Recording 13、PT 29、UI 12，共 88 个 QtTest 成功结果（含各组初始化和清理），80 个功能结果，0 失败、0 跳过。覆盖灰度 C1/C3 与像素一致性、16 位 PT 输入、真实 YOLOv5/8、TorchScript、合成 SBS 视频、原色恢复、六页导航及导出。证据为 `CTest-2026-10-06.log`、`ctest-qa.json`。
- 录制验证实际解码首末帧、帧数、来源视频与摄像头时间基准、奇数尺寸边缘补齐、开始 / 结束 / 再次开始、EOF / 取消 / 错误封口、停止正在 forward 的有效尾帧；停止后不新建片段。UI 真实文件对话框导出 AVI / JSON 与原文件逐字节一致，错误扩展名不写文件。录像列表和灰度单目播放通过。
- DEB 权限、所有权、301 个 ELF 的运行依赖、许可证与源码校验通过。APT 模拟未要求删除系统包；以普通用户在只读应用树中执行真实 ONNX、现代 PT 和旧版 PT 推理通过。证据为 `qa-report.json`。
- 私有离线命名空间内实际 dpkg 安装、普通用户推理及卸载通过；用户数据保留，宿主 dpkg 状态与集成未改变。证据为 `install-qa.json`。
- 正式包 X11 灰度 PT 推理产生 5 个目标，PNG / JSON / CSV 导出通过；未覆盖标注的像素保持灰度，PNG / JPEG / WebP / TIFF 读写与 SVG 插件通过。六页侧栏和新录制控件在 1260×820 完整可见。证据为 `desktop-qa.json` 与四份界面截图。
- 家目录程序与源码已更新；保留原 runtime 的彩色、灰度 PT GUI 自检通过，原偏好和历史文件哈希未改变。证据为 `home-qa.json`。

摄像头时间基准由录制单元测试模拟实时图像帧验证，双目路径使用合成左右拼接视频验证；未进行摄像头硬件和驱动实机验证。录像为已处理的图像帧，不包含音频。当前后端均为 CPU，仅声明上述发行平台的兼容性。

## 发布文件

公开提供 `vision-studio_1.3.0-1_amd64.deb`、`vision-studio-1.3.0-complete-source.tar.xz` 和 `SHA256SUMS`。完整源码包包含应用代码、对应上游源码、许可证与重建说明。内部材料可使用 `SOURCE-SHA256SUMS` 校验；两个主文件使用 `sha256sum -c SHA256SUMS` 校验。
