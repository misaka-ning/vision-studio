# Vision Studio 2.9.2 验收

本版修复现代 PT 检测在图像边缘产生零面积候选框时，导致整个检测／评估任务中断的问题。彩色与灰度路径统一按原图边界裁剪并过滤退化框；有效结果保留原始类别、置信度与图片顺序，无有效框时正常返回零匹配。NaN／Infinity、损坏协议等异常仍严格报错。另按实际 Ultralytics 配置能力选择 FP32 参数，消除新版 `half` 重复弃用警告，不升级依赖、不修改模型。

生产源码冻结于 `c3aad7640a19698923b307f1a42a51edabe56482`。保留 C++17／Qt 6.8.3、Fluent 深色界面以及现有 CPU／NVIDIA GPU 架构。下面区分开发阶段常驻 worker 复验、最终只读 DEB 验收和宿主安装，不把其中一项替代另外两项。
