# Vision Studio 2.5.0 验收材料

**状态：待验收。** 本目录当前仅准备本版验收工具与执行说明，没有生成 Qt／Python、真实模型、最终包、GPU、安装或源码的通过报告。不得从 2.4.0 复制 JSON、原始日志、截图、性能数字或通过结论充当本版证据。正式发行说明见 [2.5.0](../../2.5.0.md)。

## 本版专项与来源区分

- 同一个选择器实际确认目录与 YAML／YML、目录双击浏览、取消、非法类型／不存在路径行内提示；旧箭头入口移除。
- 数据集设置为 Qt::Popup，锚定按钮，支持再次点击、外部点击、Esc、关闭按钮与忙时锁定；长错误完整可读／复制／滚动。展开高级参数前后工具栏和画布几何不变，窗口调整／切页安全收起。
- 检测与评估分别占完整工作区；切页保留模式、配置指纹、范围和缓存，不发起推理。检测保留参数／画布／队列／目标表，评估使用全宽指标／曲线／报告。
- 大队列 GUI 分片创建、可见缩略图的有限后台加载、原图与缓存异步回看、GUI 心跳、快速选图后真实像素与源路径一致、灰度、清空后拒绝过期结果。合成图片用于验证调度，不作为模型准确率或部署性能数据。
- 保留常规检测、三种范围、停止回看、CPU／CUDA、PT／TorchScript、灰度 C1／C3、左右目／录像、模型显示、转换、评估报告和最终安装／源码验收。私人数据仅保留不含图片、标签、配置正文和完整清单的必要摘要。

## 工具与执行次序

四个脚本从上一正式版复制后只在本目录适配，历史版本脚本保持原样。它们不执行预设通过，不把「工具准备」算作实际验收。

1. `summarize_regressions.py --snapshot-only`：在源码与生产 Release 二进制冻结后、执行完整测试前记录输入、应用、测试程序与 CMake 配置的 SHA256。默认构建为 `output/build/2.5.0-release`，资源根须为 `/opt/VisionStudio`。
2. 实际执行完整 18 套 CTest（含真实 CUDA），保留 runner 的原始 log、JUnit、设备证据与 CUDA profile。`summarize_regressions.py` 聚合时严格核对与测试前快照一致、套件集合完整、日志和 JUnit 无失败／跳过、真实统计及 CUDA 节点；不接受混入其他版本的结果。
3. 构建最终 DEB、应用源码与完整对应源码包，实际运行离线只读包检查、隔离安装／卸载、CPU／CUDA 和公开标注集矩阵；保留包 SHA256 绑定与原始日志。`verify_folder_package.py` 重用本版成功包矩阵的只读提取目录，以未改动 COCO8 真实标注检查旧绝对根／名单的受限迁移及真实 ONNX CPU 评估。该 CLI 检查不替代选择器／Popup 的真实 UI 测试。
4. `verify_source_bundle.py`：逐文件读取并核验干净冻结源码、应用归档、完整包、18 份上游材料、运行时元数据、暂存树与最终 DEB。新 `lazyimagequeue.cpp/.h`、`asyncimagepreview.cpp/.h` 和 `evaluationpanel.cpp/.h` 必须在源码中，所有对应字节与打包文件须一致。脚本只写一个此前不存在的报告，不执行应用推理。
5. `finalize_reports.py`：全部实际检查完成后，读取最终 DEB／源码以及既有真实报告，核对 GPU 七项、转换、评估矩阵、文件夹迁移、只读私人数据摘要及新 UI／队列具名 PASS。额外的 `ui-queue-qa.json` 由实际原始日志推导，记录四种布局、标准 YOLO 数据集的部分队列观察／运行锁定／停止分片调度，以及该次心跳观察；绑定 DEB 仅用于追溯，不能据此宣称单独执行了安装包 UI 检查。

聚合脚本不会重新运行推理，不能代替完整测试。源码或二进制在测试后改变时必须按影响重新构建并重验，不通过改写旧快照／原始日志取得一致。最终通过数字、硬件、限制、失败诊断与修复后复验均由实际执行补写；当前不提供任何完成结论。

## 发布与保留

QA 与原始日志入库，Release 仍只有 DEB、完整对应源码、SHA256SUMS 三个手动附件。完成远端标签／发布状态／逐资产大小和 SHA256 核验后才按规范保留本地 2.5.0 与 2.4.0，不能提前删除 2.3.1 或独立构建中的唯一资料。Windows 2.5.0、物理摄像头与足球专项准确率均不作为本版已执行项目。
