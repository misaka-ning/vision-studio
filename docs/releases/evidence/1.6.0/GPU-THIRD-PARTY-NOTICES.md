# Optional NVIDIA runtime components

This user-installed environment is separate from the AGPL application and bundled CPU runtime.
Each dependency retains its original license; NVIDIA CUDA/cuDNN redistributables are proprietary, not relicensed under AGPL.
Publisher license texts supplied by the wheels are preserved under licenses/. Exact versions and metadata are in gpu-license-inventory.json.
