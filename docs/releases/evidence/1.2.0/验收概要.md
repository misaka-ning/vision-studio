# Vision Studio 1.2.0 验收概要

发行平台为 Ubuntu 22.04 amd64，默认安装到 `/opt/VisionStudio`。维护者为 misaka_ning <1468549029@qq.com>，应用源码按 AGPL-3.0-only 发布。

本版提供 RGB / BGR / 灰度输入，灰度自动适配模型的 1 或 3 通道。单设备左右拼接摄像头和视频可选完整画面、左目或右目，预览、推理及导出对应同一份画面。设置持久化，单目坐标以裁切画面为基准，JSON 同时记录原始帧尺寸。图片保持完整输入。

## 已执行验证

- 三套 CTest 全部通过：Core 31、PT 24、UI 10，共 65 个 QtTest 成功结果（包含各组初始化和清理），0 失败、0 跳过。59 个功能结果覆盖灰度亮度、平面一致性、C1/C3 ONNX、真实 YOLOv5/8、首层为C1的完整权重、TorchScript、合成SBS视频、眼内坐标、UI设置迁移及真实单目导出。日志为 `CTest-2026-10-06.log`。
- DEB 权限、所有权、301 个 ELF 的运行时依赖、许可证和源码校验通过，APT 模拟未要求删除系统包。只读应用树中以普通用户执行真实 ONNX、现代 PT 和旧版 PT 推理。证据为 `qa-report.json`。
- 私有离线命名空间内实际 dpkg 安装、普通用户推理及卸载通过；用户数据保留，宿主 dpkg 状态及集成未改变。证据为 `install-qa.json`。
- 正式 DEB payload 的 X11 灰度 PT 推理产生 5 个目标，PNG / JSON / CSV 导出通过；PNG / JPEG / WebP / TIFF 读写和 SVG 插件通过。新摄像头模式控件在1260×820完整可见。证据为 `desktop-qa.json`、`ui-preview.png`、`ui-camera.png`。
- 家目录便携版程序和源码已更新；其原有 runtime 的 RGB、灰度 PT GUI 自检均通过，原偏好及历史文件哈希未改变。证据为 `home-qa.json`。

双目路径使用合成拼接视频验证，未进行摄像头硬件或驱动实机验证。当前后端为 CPU。仅声明上述发行平台的兼容性。
