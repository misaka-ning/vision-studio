# Vision Studio 2.9.2

修复 PT 检测／评估在某张图片处意外中断的问题，并消除新版 Ultralytics 反复出现的 `half` 弃用警告。

## 修复内容

- 部分低置信度候选框裁剪到图像边缘后，宽或高会变为零。现在彩色与灰度 PT 路径统一过滤这类退化框，保留其他有效结果；没有有效框的图片正常完成，后续图片继续处理。
- 保留模型原始类别 ID、置信度和批量图片顺序；非有限坐标、损坏协议等异常继续明确报错，不将真正的推理错误伪装成空结果。
- FP32 参数根据实际接口能力选择：新版使用 `quantize=None`，兼容旧接口的 `half=False`。推理仍为 FP32，模型和运行依赖保持。
- 沿用 C++17／Qt 6.8.3、Fluent 深色界面以及 CPU／NVIDIA GPU 后端，数据集评估、阈值分析、报告、模型显示与转换等操作保持。

## 实际验收

- 完整执行 26 套生产回归：432 项 Qt、159 项 Python，零失败／跳过。
- 原失败队列在 CPU／CUDA 常驻 worker 中各完成 1223 张，覆盖局部批量、尾批、零匹配和源文件不变校验。
- 使用最终 DEB 启动真实 Qt 工作台，在原模型与数据集上完成 CUDA 评估 **1223／1223 张**，验证 C++ 严格解码、队列顺序及完整评估流程；原模型、图片、标签和清单保持。
- 最终包的 CPU／CUDA 后端、公开 COCO8 评估、报告与转换等适用门禁、完整对应源码、隔离安装及宿主实际升级验收通过。宿主已安装 `2.9.2-1`。

完整范围、原件承诺和验收编排失败后的重试说明见[同版证据](https://github.com/misaka-ning/vision-studio/blob/v2.9.2/docs/releases/evidence/2.9.2/README.md)。私人数据与模型精度不公开；上述检查是工作流与结果契约验收，不是精度或速度基准。
