# Vision Studio 2.9.2

修复 PT 检测与评估运行到某张图片时，因图像边缘零面积候选框而整项中断的问题。

- 现代 PT 的彩色与灰度路径统一裁剪到原图并过滤宽／高为零的框，保留有效框、原始类别与置信度，以及批量图片顺序。没有有效框的图片正常完成；非有限坐标和损坏协议继续报错。
- 按实际 Ultralytics 接口传递 FP32 参数，新接口使用 `quantize=None`，兼容旧接口 `half=False`，避免重复弃用警告；未修改运行依赖或模型。
- 保留 C++17／Qt 6.8.3、Fluent 深色界面、CPU／NVIDIA GPU、数据集评估与阈值分析、报告、模型显示与转换等既有功能。

实际测试、最终包与交付状态见[同版证据](https://github.com/misaka-ning/vision-studio/blob/v2.9.2/docs/releases/evidence/2.9.2/README.md)。当前验证与打包仍在进行，未执行的检查不声明通过。

本版为 Ubuntu 22.04 amd64，Debian `2.9.2-1`，安装到 `/opt/VisionStudio`。三个手动附件为 DEB、完整对应源码包和 `SHA256SUMS`。Windows 已发布补充版为 2.9.1，本次未提供 Windows 2.9.2 安装包，历史标签和资产保持不变。
