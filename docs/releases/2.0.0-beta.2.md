# Vision Studio 2.0.0-beta.2

本版修复批量图片检测结果无法回看的问题。Beta.1 导入文件夹并检测完全部图片后，重新点击队列中的旧图片只显示原图；本版保存每张已完成图片的本轮识别结果，切换队列时恢复该图片的标注、目标表、指标和当前导出对象，无需重新检测。零目标结果也可回看和导出；未处理图片显示原图。

回看不会重复推理、追加运行记录或触发自动导出。本轮结果以临时缓存供当前会话使用，清空、开始新任务、切换模型／预览模式／计算设备或关闭程序时释放；需要永久保留时使用手动或自动导出。

保留 Beta.1 的 Fluent 风格界面、全局模型选择与 Netron 缓存，以及 CPU／NVIDIA GPU、PT／ONNX、灰度 C1／C3、左右目、录像和导出支持。推理后端与模型输入输出约定不变。完整变更见 [更新日志](https://github.com/misaka-ning/vision-studio/blob/v2.0.0-beta.2/CHANGELOG.md)。

## 验收

最终 Release 构建已完成全部 8 组 CTest（176.359 秒），零失败、零跳过；GPU 后端 10 项与录像 14 项均通过。批量结果回看专项覆盖彩色、灰度、零目标、反复切换、当前图片导出、原始推理配置保留、无重复运行记录以及缓存清理，3 个功能场景通过，QtTest 共 5 项通过。发布／清理安全 48 项、版本元数据 11 项测试通过。

最终 DEB 已通过普通用户真实 ONNX／现代与旧版 PT、ONNX／PT 结构图／层级树／参数表及缓存复用、APT 依赖模拟；隔离离线安装／卸载通过，用户数据保留且宿主 DPKG 与桌面集成未变。包内 ONNX CUDA、PT CUDA、ONNX CPU、PT CPU 四轮真实启动器均通过，结果与导出记录实际设备。实际 RTX 4060 ONNX 运行的新 trace 包含 364 个 CUDA 节点事件。同版包报告绑定最终 DEB SHA256，与原始日志保存在 [验收证据](https://github.com/misaka-ning/vision-studio/tree/v2.0.0-beta.2/docs/releases/evidence/2.0.0-beta.2)。完整对应源码的逐项 SHA256／文件核验记录见同目录 `source-bundle-qa.json`；该报告与冻结文件清单在归档生成后加入仓库，避免递归自校验，产品与构建输入保持冻结。物理摄像头未实测。

## 文件与安装

应用版本与发行目录为 `2.0.0-beta.2`，标签为 `v2.0.0-beta.2`。CMake 数字版本保持 `2.0.0`，Debian Control Version 为 `2.0.0~beta.2-1`。公开文件名使用安全的 `-beta.2`；APT／DPKG 根据包内版本排序。

本版提供三个手动附件：

- `vision-studio_2.0.0-beta.2-1_amd64.deb`
- `vision-studio-2.0.0-beta.2-complete-source.tar.xz`
- `SHA256SUMS`

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.0.0-beta.2-1_amd64.deb
vision-studio
```

安装目标为 Ubuntu 22.04 LTS amd64，目录为 `/opt/VisionStudio`。个人设置、模型、运行记录、导出和录像保留。新代码采用 AGPL-3.0-only，第三方组件保留原始许可。

完整源码包重新生成本版应用源码与清单，保留同一套 15 份原始上游源码和通知；GitHub 自动提供的源码 ZIP／tar.gz 不能替代它。QA 随仓库保存，不作为额外 Release 附件。

GitHub Release 标记 Pre-release，明确 `latest=false`，正式版 Latest 保持 1.6.0。远端标签和三个资产的大小／SHA256 全部核验后，本地保留最新 Beta 与 1.6.0；旧 Beta 副本须逐版精确核验后清理。已发布标签、核心资产和归档不可覆盖。
