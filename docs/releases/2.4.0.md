# Vision Studio 2.4.0

本版聚焦标准 YOLO 数据集评估与视频／摄像头推理，精简输入方式并重新布局工作台。继续使用 C++17／Qt 6.8.3、Fluent 深色界面、全局模型和现有 CPU／NVIDIA GPU 后端，无新增运行依赖。

## 主要变化

- 公开输入集中为「YOLO 数据集」「视频」「摄像头」。独立图片、普通图片文件夹、图片拖入、更多页运行示例和公开 `--demo`／`--pt-demo` 退出支持，启动不自动载入示例图片。
- Ctrl+O 直接导入标准 YOLO 数据集文件夹；数据集按钮旁菜单继续支持明确选择 YAML。根目录配置解析、失效路径只读迁移和失败后重试沿用既有规则。
- 顶部输入与设备合并为紧凑任务条。数据集模式、摘要和集合操作保留一行；详细模型类别映射、可选审核 metadata 与扫描配置归入折叠的「数据集设置」。校验状态仍可见，可展开查看原因。
- 数据集图片队列、「检测当前集合」／从当前向后／仅当前范围、GT 对照、评估与阈值、错例联动、后台保存、停止和结果回看继续保留；视频／摄像头、灰度与双目、录制、模型库、结构显示与转换沿用原有能力。默认「检测当前集合」仅处理当前选择的 Train／Val／Test 集合，不跨集合合并。
- 个人设置、模型、运行记录、录像、历史评估报告及已采用配置保留。已公开标签、旧安装包与完整源码包不改写。

## 兼容边界与验收

标准 YOLO 数据集仍需 YAML 指定类别与集合；只有普通图片目录不再作为工作台输入。图片检测与评估复用数据集队列，检测预览不等于执行评估。分类推理后端保留，目标检测评估仍只支持所选目标类别；COCO ID 32 是 sports ball，不能当作仅足球识别。

本版实际构建、Qt／Python 回归、真实模型、最终 DEB、隔离安装、CPU／CUDA、数据集评估与完整对应源码检查以[同版验收证据](https://github.com/misaka-ning/vision-studio/blob/v2.4.0/docs/releases/evidence/2.4.0/README.md)及原始日志为准。发布前完成适用检查；本说明不提前将未执行项目写为通过。内部 `--smoke`／`--smoke-pt` 保留开发与发行验收用途，不是普通图片输入入口。Windows 2.4.0 与物理摄像头不作为已验收项目。

## 安装与源码

正式标签为 `v2.4.0`，Debian 版本为 `2.4.0-1`，默认安装到 `/opt/VisionStudio`。Linux Release 保持三个手动附件：

- `vision-studio_2.4.0-1_amd64.deb`
- `vision-studio-2.4.0-complete-source.tar.xz`
- `SHA256SUMS`

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.4.0-1_amd64.deb
```

升级前结束检测、评估、录像与模型转换，导出需要永久保留的临时结果，退出旧应用后安装。用户资料与已准备的 GPU 环境保留。完整源码包含应用源码与需要交付的原始上游源码、来源、许可和校验；GitHub 自动源码 ZIP／TAR 不替代完整对应源码包。

远端标签、发布状态、三个附件大小与 SHA256 核验成功后，按规范保留本地 2.4.0 与 2.3.1，并逐版检查旧发行／独立构建副本。历史远端标签、Linux 核心附件与 2.1.0 Windows 补充包保持原样。
