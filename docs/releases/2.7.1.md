# Vision Studio 2.7.1

修复 Fluent 深色界面中下拉菜单顶部和底部的白色边条。应用统一使用深色调色板，让 Qt 原生弹窗外框和上下留白与列表保持一致；设备、GPU 编号、颜色模式、检测范围等下拉框统一生效。选项与交互、检测、评估、模型显示及转换逻辑保持原有行为，无新增依赖。

实际 Qt 主窗口展开检查已确认四处菜单的浅色边条消失，Escape 不改变当前选择。一次完整22套回归（396项Qt、101项Python，零失败/跳过）、最终包CPU/CUDA、转换、公开评估、隔离安装/卸载及完整对应源码验收已实际通过。状态及适用范围见[同版证据](https://github.com/misaka-ning/vision-studio/blob/v2.7.1/docs/releases/evidence/2.7.1/README.md)。

正式交付为 DEB、完整对应源码包和 SHA256SUMS 三个附件。安装位置 `/opt/VisionStudio`，个人设置、模型、运行记录、录像、评估报告及独立 GPU 环境保留。2.7.0 标签与资产不覆盖。
