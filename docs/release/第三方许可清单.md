# 第三方许可清单

本清单对应正式 DEB 的实际发行环境。新编写的 Vision Studio 代码由 misaka_ning <1468549029@qq.com> 按 **AGPL-3.0-only** 发布。第三方组件保持原始许可；此摘要不能替代保留的许可原文。

## 原生库、模型与通知

| 组件 | 本次使用 | 原始许可与材料 |
| --- | --- | --- |
| Qt | 6.8.3 qtbase / qtsvg / qtwayland / qtimageformats，共享库与插件 | Qt 代码采用 LGPLv3 选项；嵌入第三方组件许可单独保留；四个完整源码归档随附 |
| QtImageFormats 内嵌 libwebp | 由官方 6.8.3 源码构建 | BSD 许可与 PATENTS / 版权通知在原源码及 `licenses/qt/source-notices/` |
| ICU | SDK 内 ICU 73.2 | `licenses/qt/ICU-73.2-LICENSE.txt` 保留 Unicode 及内含组件通知 |
| FFmpeg | OpenCV wheel 中 5.1.6 | 实际库报告 LGPL-2.1-or-later，原始源码和构建配方随附；`licenses/FFMPEG-BUILD.json` 记录实际配置 |
| Native OpenCV | 系统 OpenCV 4.5.4 | 由 Ubuntu 系统包依赖提供，保留系统包授权及版权材料 |
| 系统 Python / GNU 运行库 / BLAS / LAPACK | Ubuntu 22.04 系统软件包 | 由 Debian Depends 安装；未复制 wheel 内 GNU 库或旧 OpenCV OpenBLAS 到发行负载 |
| YOLOv8n 权重 | 官方 assets v8.3.0 | AGPLv3；`models/yolov8n.provenance.json` 与 `licenses/models/` |
| YOLOv5n 权重 / 图片 / ONNX | 官方 YOLOv5 v6.0；ONNX 做固定输入转换 | GPLv3；`models/` 的来源和哈希记录 |
| YOLOv5 网络兼容代码 | vendored v7.0 | GPLv3；完整源码与 `vendor/yolov5/LICENSE` |

Qt 6.8 的官方授权说明区分 Qt 模块许可和第三方代码，并从该版本开始提供 SPDX 软件清单。本次保存实际 SDK 的三个模块 SPDX，以及独立构建 QtImageFormats 的原始 SPDX；SDK 清单含构建与测试依赖，不能把其中全部条目都视作随包二进制。[Qt 许可与 SBOM](https://doc.qt.io/qt-6.8/licensing.html)

FFmpeg 的适用许可取决于启用组件；这里以实际库报告、配置和上游源码为依据，并保存原始源码与构建方式。[FFmpeg 官方许可说明](https://ffmpeg.org/legal.html) 无 GUI OpenCV wheel 的组件说明见 [OpenCV Python 官方发行说明](https://pypi.org/project/opencv-python-headless/4.11.0.86/)。

## 许可正文和对应源码

完整 AGPLv3、GPLv3、LGPLv3、LGPLv2.1 和 Apache-2.0 正文在 `licenses/texts/`。模型、Python 包和 Qt 原始通知分别位于 `licenses/models/`、`licenses/python/`、`licenses/qt/`。安装后的主许可目录为 `/usr/share/doc/vision-studio/licenses`，版权摘要为 `/usr/share/doc/vision-studio/copyright`。

对应源码以配套完整源码包交付，包括本项目代码、四个 Qt 原始源码归档、Ultralytics / THOP 官方源码发行包、OpenCV / wheel 构建配方与 FFmpeg 5.1.6 源码。组件来源和哈希见 `SOURCE-INVENTORY.json`，重建与 Qt 替换方法见 `对应源码与重建.md`。维护者没有将第三方资源重新授权为应用许可。
