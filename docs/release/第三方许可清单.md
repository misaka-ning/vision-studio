# 第三方许可清单

本清单对应 2.1.0 的实际 CPU 发行环境；最终 DEB 功能与安装验收独立执行。新编写的 Vision Studio 代码由 misaka_ning <1468549029@qq.com> 按 **AGPL-3.0-only** 发布。第三方组件保持原始许可；此摘要不能替代保留的许可原文。

## Fluent 界面视觉参考（沿用 2.0）

Fluent-Qt v1.9.2 仅用于视觉参考，没有作为运行库链接，也不分发其字体、微软图标、Gallery 或截图。原 MIT、参考说明和来源记录保存于 `licenses/fluent-qt-design-reference/`；应用自己的 `assets/fluent-dark.qss` 与新 checkmark SVG 是 AGPL-3.0-only 源码。源码归档递归包含 `assets/`、`packaging/licenses/`；DEB 同样递归复制这些资源与已经保存的通知，不会根据引用自动联网取得其他许可文件。

## V1.6 可选 GPU 用户环境

正式 DEB 的随包 Python 清单仍为下文的独立 CPU／Netron 运行时。GPU CUDA／cuDNN 二进制不打进 DEB 或 Release；用户主动准备后从 PyTorch 官方索引和 PyPI 安装到个人数据目录，两个环境不能混为同一个发行负载。

GPU 环境锁定 PyTorch `2.9.1+cu128`、Torchvision `0.24.1+cu128`（BSD）、ONNX Runtime 1.23.2（MIT），保留 Ultralytics AGPL 与 YOLOv5 兼容依赖。安装使用完整 78 项版本／官方 wheel SHA256 锁，包括仅在用户环境内的 pip 26.2.1 下载工具。NumPy、OpenCV headless、FFmpeg 等嵌入组件保持上游许可；GPU wheel 不执行 DEB 的 strip／GNU 库重绑定。

NVIDIA CUDA 12.8、cuDNN 9.10.2.21、cuBLAS／cuFFT／cuRAND／cuSOLVER／cuSPARSE／cuSPARSELt／NVRTC／nvJitLink／cuFile 等保持 NVIDIA 原始专有许可。NCCL／NVSHMEM 的发行元数据为 BSD，NVTX 为 Apache；最终以各 wheel 随附原文与组件通知为准，不把全部 NVIDIA 组件统称为一种许可，也不重新声明为应用的 AGPL。

准备脚本将实际 wheel 的许可证和 NOTICE 复制到 `gpu-runtime/licenses/`，写入 `gpu-license-inventory.json`、`GPU-THIRD-PARTY-NOTICES.md` 和 `installed-packages.txt`。独立 GPU 环境不随应用发行包提供；如自行再分发这些二进制，需另外遵守其原始许可条款，不能用本项目 AGPL 正文替代。[CUDA EULA](https://docs.nvidia.com/cuda/eula/index.html)、[cuDNN EULA](https://docs.nvidia.com/deeplearning/cudnn/backend/latest/reference/eula.html)、[ONNX Runtime](https://github.com/microsoft/onnxruntime/blob/v1.23.2/LICENSE)。

应用完整源码包含 GPU 配置／探针代码、依赖锁和说明；NVIDIA 闭源运行库并不存在可交付为 AGPL 的对应源码。源码包内的 Qt／FFmpeg／Ultralytics 等对应源码与原通知继续完整交付。C++ 所用 ONNX Runtime API 头文件保留上游 MIT 许可与版本来源。

## 模型转换的原生依赖与通知

ONNX 1.17.0 使用 Apache-2.0，源码中的 pybind11 使用 BSD-3-Clause。Python protobuf 6.33.0 使用 BSD-3-Clause，对应官方 v33.0 完整源码；ONNX 官方 Linux wheel 另静态链接 C++ protobuf 3.21.12，其 BSD-3-Clause 原文及源码也保留。这不是 59 个 Python 发行版之外又安装了一份 Python protobuf，不能用 Python 包的版本字段替代 ONNX 原生扩展嵌入组件的身份。

四份原始 LICENSE 位于 `licenses/model-conversion/`，`PROVENANCE.json` 记录来自 ONNX、完整 protobuf v33.0、C++ protobuf 3.21.12 的归档成员、字节数与 SHA256。ONNX sdist 原许可保存在这里，wheel 随附许可另在 `licenses/python/onnx-1.17.0/` 保存；不重新排版或把同名文件强行视作字节相同。新增三份原始源归档将上游材料总数从 15 增至 18，原 15 份、Qt SDK SPDX、Qt／Chromium 源码通知保持原样；本版仅重收实际 Python 59 项清单。

## 许可正文和对应源码

完整 AGPLv3、GPLv3、LGPLv3、LGPLv2.1 和 Apache-2.0 正文在 `licenses/texts/`。模型、Python 包、Netron 前端和 Qt 原始通知分别位于 `licenses/models/`、`licenses/python/`、`licenses/netron/`、`licenses/qt/`，转换原生组件另见 `licenses/model-conversion/`。安装后的主许可目录为 `/usr/share/doc/vision-studio/licenses`，版权摘要为 `/usr/share/doc/vision-studio/copyright`。
