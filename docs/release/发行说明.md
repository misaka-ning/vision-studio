# Vision Studio 2.1.0

2.1 新增模型库右键管理与 PT → ONNX / TorchScript 转换，保留 Fluent 深色界面、CPU／NVIDIA GPU、灰度 C1／C3、左右目处理、录像、批量结果回看与个人数据约定。

## 模型库与转换

模型条目右键提供打开位置、添加／修改备注、重命名显示名称和从列表移除。菜单作用于点击的条目，右键本身不切换全局模型；名称与备注持久保存，重命名不改磁盘文件名、路径、类别或权重，移除保留原始文件。拖动排序继续保持全局选用。

新增「模型转换」位于「录制视频」之后、「更多」之前。来源默认使用全局模型，开始后固定本次来源，支持兼容的现代 Ultralytics 检测／分类、旧版 YOLOv5 检测完整 PT 与带必要元数据的标准 TorchScript，导出 ONNX 或 TorchScript。导出采用 CPU FP32、batch=1、固定正方形输入、不含 NMS，保留 C1／C3；输入尺寸为 32 的倍数，ONNX 可选 Opset 12／17，TorchScript 归档保存 `config.txt`。

后台进度、阶段日志与取消独立于检测设备选择；保留原模型，拒绝覆盖已有输出。如果完整文件已在取消请求前写出，界面提示完成或保留该结果。成功后可打开输出文件夹或明确点击「加入模型库」，完成本身不自动替换当前模型。入库时记录转换元数据，选用时应用任务、类别、输入尺寸与默认归一化，用户手工导入的标签仍优先；C1 自动选择灰度，C3 仍需按训练预处理选择颜色模式。默认输出为个人数据目录的 `converted-models/`，可选择其他可写目录。

转换器针对旧版 OpenCV 的部分静态形状和广播限制做等价规约，输出仍为标准 ONNX。保存前执行图检查及转换环境 Python OpenCV CPU 输出比较，系统 C++ OpenCV、实际图片与 GPU 后端仍须分别验证。转换不能补齐裸权重或未知自定义类的架构，也不提供 ONNX → PT 图转换或原始可训练检查点还原。固定输入跟踪不承诺保留未知动态控制流或训练功能；灰度与左右目裁切仍在工作台选择。

## 推理、结果与兼容范围

CPU ONNX 使用 C++ OpenCV DNN，可选 NVIDIA GPU 使用 C++ ONNX Runtime CUDA；PT 使用常驻 Python／PyTorch，兼容现代 Ultralytics、随附 YOLOv5 框架的完整检查点和标准 TorchScript。Netron 结构图、层级树、参数表共用模型库全局选择和缓存；普通 PT 的静态包含关系不是完整 forward，查看运算连接建议使用 ONNX。

保留参数滚轮保护、后台结果写入、保存目录入口与排序。文件夹中已完成图片可回看标注、目标和指标，手动导出保存当前所选结果；缓存仅用于当前会话，更换来源、开始新任务、切换模型／预览模式／设备或关闭程序时释放，需要永久结果请导出。停止不等待已接受的后台写入，写入收尾后再允许新任务；CPU 当前 OpenCV forward 需自然结束，CUDA／PT 保留各自取消机制，界面持续响应。

TensorRT、AMD／Intel GPU、分割、姿态、旋转框、内置 NMS 或多图像输入 ONNX 不在本版支持范围。物理摄像头应按真实设备验证。详细预处理、任务与格式见 `docs/模型说明.md`、`docs/使用指南.md`。

DEB 携带离线 CPU／Netron／转换环境；GPU wheel 由用户主动准备到个人目录，不在 APT／DPKG 安装中下载或修改显卡驱动。CPU 转换无需准备 GPU 环境。

## 交付与安装

应用与源码归档版本为 `2.1.0`，标签 `v2.1.0`，Debian 包版本 `2.1.0-1`；正式 Release 采用 `prerelease=false` 并更新 Latest，仅提供三个手动附件：

- `vision-studio_2.1.0-1_amd64.deb`
- `vision-studio-2.1.0-complete-source.tar.xz`
- `SHA256SUMS`

完整对应源码包含应用拆分归档、`SOURCE-INVENTORY.json`、`SOURCE-SHA256SUMS` 与 18 份原始上游源码／构建输入。原 15 份保持字节，新增 ONNX 1.17.0、Python protobuf 6.33.0 对应 v33.0 源码，以及 ONNX wheel 静态 C++ protobuf 3.21.12 源码和原通知。GitHub 自动源码 ZIP／tar.gz 不能替代完整包；QA 报告与原始日志随同版仓库证据保存，不增加附件。

目标 Ubuntu 22.04 LTS amd64，安装到 `/opt/VisionStudio`。应用采用 AGPL-3.0-only，第三方保留原始许可。

```sh
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.1.0-1_amd64.deb
vision-studio
```

可从 2.0.0 或此前 Beta 升级。先结束检测、录像与转换，导出需要保留的临时结果，退出旧程序再安装；个人设置、模型、运行记录、导出、录像和 GPU 环境保留，会话回看缓存不跨重启保存。
