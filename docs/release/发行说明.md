# Vision Studio 1.5.0 发行说明

维护者：misaka_ning <1468549029@qq.com>。本次交付为本地 DEB 与配套源码文件，没有上传到公共仓库。

## 安装与启动

发行平台为 Ubuntu 22.04 amd64（x86_64），使用 C++17 / Qt 6.8.3。正式包包含 Qt / WebEngine 运行库、浏览器辅助进程与资源、独立的 Python 3.10 CPU 环境、Netron 9.3.1、YOLOv8n / YOLOv5n 检查点及 ONNX 示例。安装后无需在线下载模型、页面或 Python 依赖；APT 可能需要安装包声明的系统共享库。

```bash
sudo apt install ./vision-studio_1.5.0-1_amd64.deb
vision-studio
```

也可从应用菜单启动 Vision Studio。程序文件位于 `/opt/VisionStudio`，发行文档和许可位于 `/usr/share/doc/vision-studio`。首次体验可在「更多」点击「运行示例」。完整操作见上一级目录的 `使用指南.md`。

设置、运行记录及默认导出位于 `${XDG_DATA_HOME:-$HOME/.local/share}/vision-studio`，其中 `preferences.ini` 保存设置，`history.json` 保存记录，`results/` 保存结果，`recordings/` 保存标注录像及其元数据。可通过 `VISION_STUDIO_DATA_DIR` 指定另一数据目录。卸载程序不会要求清除个人导出；保留与清理这些用户文件由用户自行决定。

```bash
sudo apt remove vision-studio
```

## 本次功能与运行时

图片及批量图片、视频和摄像头输入，目标检测和单标签分类，PNG / JSON / CSV 导出，结果缩放和平移，模型库与运行记录。图片批量任务可逐张自动导出；视频与摄像头任务结束后导出最后一帧。

1.5.0 为模型显示增加「结构图」「层级树」「参数表」三种模式，搜索与详情支持检查当前可解析的信息。三种模式共用全局模型和一次解析缓存，切换不重新加载。修复嵌套对象的白底浅字问题，使图、树、表和详情保持深色可读。

七页导航依次为「检测工作台」「模型库」「模型显示」「运行记录」「使用指南」「录制视频」「更多」。模型库中的模型选择全局生效，统一用于工作台检测与模型显示；选择后在后台异步预加载结构，完成后进入页面直接显示缓存。页面导航不切换模型。不识别、损坏或没有可显示结构的文件以中文说明反馈，并提供重试。页面由本机回环地址随机端口提供，文件留在本机，不上传远程服务；结构查看不执行 `torch.load`。ONNX 显示声明的运算图，普通 PT 只展示模块包含关系、权重分组及静态信息，不补造 forward 连接。

`.pt` 等文件的静态信息可能不完整；任何非 ONNX 文件均显示以下提示：

想看完整结构，建使用导出的 ONNX。

保留 1.3.0 的灰度预览、单设备左右拼接画面选择及标注视频录制。运行示例与手动导出入口仍在「更多」。ONNX 自动识别固定 1 / 3 输入通道；灰度统一使用一个均值，检测补边保持 114。摄像头与视频可使用完整画面、左目或右目，检测坐标和导出相对所选画面；保留设备默认分辨率，奇数宽度时右目多一列。图片始终完整处理。旧版默认彩色与完整画面设置继续兼容。

现代 Ultralytics、兼容旧版 YOLOv5 和标准 TorchScript `.pt` 也可使用 1 / 3 通道灰度模型；手工均值保持零，检测仍除以 255，灰度分类使用 Ultralytics 分类变换并统一 `mean=0`、`std=1`。通道与必要元数据约定见 `模型说明.md`。

视频或摄像头开始推理后可开始 / 结束录制，保存所选眼、实际灰度或彩色画面与检测标注。录像以 MJPEG AVI 和同名 JSON 保存，在「录制视频」页浏览和播放；图片批量任务不录制。灰度预览及 PNG 底图显示实际灰度，切回彩色恢复原色并清除旧检测，需要重新推理。

ONNX 使用 C++ / OpenCV DNN 4.5.4 CPU；`.pt` 使用常驻本地 Python / PyTorch CPU 进程。发行环境为 Python 3.10、PyTorch 2.9.1+cpu、Torchvision 0.24.1+cpu、Ultralytics 8.4.173、NumPy 2.2.6、opencv-python-headless 4.11.0.86、Netron 9.3.1。完整的 57 个随包 Python 发行版记录在 `licenses/PYTHON-DISTRIBUTIONS.json`，安装目录的 `requirements-pt.lock.txt` 是该包实际锁定清单。无 GUI OpenCV wheel 避免再引入另一套 Qt；原生界面使用 Qt 6.8.3。

支持标准 Ultralytics YOLOv8 / YOLO11 完整 `.pt` 检查点、兼容随附 YOLOv5 v7.0 网络源码的旧版完整检查点，以及带任务与类别元数据的兼容 TorchScript `.pt`。内置旧版权重来自 YOLOv5 **v6.0**。裸 `state_dict`、需额外自定义网络源码的检查点、分割、姿态及旋转框模型不在当前兼容范围；详见 `模型说明.md`。加载 `.pt` 时应使用自己训练或可信来源的检查点。

当前推理均为 CPU。未提供 CUDA / TensorRT 后端。摄像头硬件及其驱动需要在实际设备上验证；本次自动测试使用本地图像与短视频。

## 验证记录

本版六套 CTest 已全部通过，分两批各执行一次，总耗时 **141.47 秒**。核心、录制、PT、UI、模型显示五套 QtTest 分别通过 34、13、29、13、16 项记录，合计 **105 项**（包含初始化与清理）；Python HTTP 服务套件的 **11 个用例**全部通过，均为 0 失败、0 跳过。汇总日志为配套源码中的 `docs/release/CTest-1.5.0-2026-10-07.log`，两批原始摘要与 details 日志也保留；发行资料中的 `ctest-qa.json` 提供结构化摘要。

核心回归用例通过真实 OpenCV forward 验证灰度亮度、C1 / C3 输入、统一均值、114 补边和通道错误；合成左右拼接视频与真实推理验证所选眼的内容、尺寸、坐标、奇数宽度和图片完整处理。模型显示用例检查三模式、缓存复用、搜索详情及静态结构边界。

另外 **11 个独立元数据边界场景**已实测通过，覆盖共享张量身份、子图同名独立权重、循环引用、深度与条数截断、4 MiB 数据上限、长字段提示及精确元素数。该探针仅对合成的已解析 Netron 元数据运行结构提取，不加载 PT 检查点或执行模型代码，**不计入 CTest 数量**。复核脚本和结果分别为发行资料中的 `metadata-boundary-qa.js`、`metadata-boundary-qa.json`，结果记录探针与实际提取脚本的 SHA256。

模型显示自检等待 Netron 真实解析并排列图节点，依次生成 `model-display.png`、`model-hierarchy.png`、`model-parameters.png` 和 `model-display-report.json`。报告记录 `nodes`、`hierarchy_items`、`parameter_rows`、`display_modes` 与 `cache_preserved`，检查三种展示内容和缓存复用。发行包检查包括普通用户、只读安装树，以及隔离网络环境中的回环页面访问。以下为检查命令，实际结果以同版本验收报告为准：

```bash
vision-studio --smoke-model /tmp/vision-studio-model-smoke
vision-studio --smoke-model /tmp/vision-studio-pt-model-smoke \
  --display-model /opt/VisionStudio/models/yolov8n.pt
```

正式 DEB 的解包、只读运行、桌面与隔离安装验收结果，以本版发行目录最终生成的 `qa-report.json`、`install-qa.json`、`desktop-qa.json` 为准；上述测试通过不预先代表这些安装包检查已完成。摄像头硬件需要在实际设备上检查。上一级 `验证报告.md` 保留早期安装的历史证据，不能替代本版执行结果。源码完整性使用主文件 `SHA256SUMS` 与拆分源码 `SOURCE-SHA256SUMS` 检查。
