# Vision Studio 2.2.0

本版新增文件夹检测范围选择与原始类别ID筛选，保持C++17 / Qt6.8.3、Fluent深色界面、现有推理后端和个人数据约定。

## 文件夹检测范围

开始按钮上方提供“检测整个文件夹”“从当前图片向后检测”“只检测当前图片”，默认全部，从队列首张开始。当前图片指输入队列选中项；后两种无选择时行内提示并阻止开始。开始时冻结范围和顺序，进度按本次图片数计算，不限制50张。停止保持异步，已交付结果可回看和导出。

同配置下每张完成后更新该图结果，停止前未重算的图片与范围外有效缓存保留；模型、参数、标签映射、筛选条件变化时清除不兼容缓存。缓存不跨程序重启保留，永久保存使用导出。

## 类别 ID 筛选

类别标签继续只映射名称。独立筛选输入留空为全部，支持32、0,2,32、空格、中文逗号并自动去重。后台读取模型实际类别数量，负数、非整数、溢出和越界值通过行内提示阻止任务；不以COCO80或标签文件行数代替实际模型类别范围。图像分类禁用筛选。

筛选保持原始class_id，统一作用于ONNX CPU／CUDA、PT、TorchScript检测，并保持框、表格、计数、自动保存、手动导出和录制一致。COCO ID32是sports ball，涵盖多种球类，不等于只识别足球。自定义ID以模型自身定义为准。

## 验证与文件

实际测试、硬件、原始失败与修复日志、最终DEB/CPU/GPU/安装/对应源码的检查保存在[同版证据](https://github.com/misaka-ning/vision-studio/tree/v2.2.0/docs/releases/evidence/2.2.0/)。报告区分实际通过、修复后复验与未执行项目。Windows2.2.0和物理摄像头不作为已实测项目。

正式发布使用v2.2.0，Debian版本2.2.0-1，安装目录/opt/VisionStudio。Release仅有三个手动附件：

- vision-studio_2.2.0-1_amd64.deb
- vision-studio-2.2.0-complete-source.tar.xz
- SHA256SUMS

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.2.0-1_amd64.deb
```

保留个人设置、模型、运行记录、导出、录像与可选GPU环境。原2.1.0 Linux/Windows资产及既有标签不覆盖；新版本远端标签、状态、大小和SHA256核验成功后，按规范保留本地2.2.0与2.1.0，清理可恢复的2.0.0发行副本。
