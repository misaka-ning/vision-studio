# Vision Studio 1.3.0 发行说明

维护者：misaka_ning <1468549029@qq.com>。本次交付为本地 DEB 与配套源码文件，没有上传到公共仓库。

## 安装与启动

发行平台为 Ubuntu 22.04 amd64（x86_64），使用 C++17 / Qt 6.8.3。正式包包含 Qt 运行库、独立的 Python 3.10 CPU 环境、YOLOv8n / YOLOv5n 检查点及 ONNX 示例。安装后无需在线下载模型或 Python 依赖；APT 可能需要安装包声明的系统共享库。

```bash
sudo apt install ./vision-studio_1.3.0-1_amd64.deb
vision-studio
```

也可从应用菜单启动 Vision Studio。程序文件位于 `/opt/VisionStudio`，发行文档和许可位于 `/usr/share/doc/vision-studio`。首次体验可在「更多」点击「运行示例」。完整操作见上一级目录的 `使用指南.md`。

设置、运行记录及默认导出位于 `${XDG_DATA_HOME:-$HOME/.local/share}/vision-studio`，其中 `preferences.ini` 保存设置，`history.json` 保存记录，`results/` 保存结果，`recordings/` 保存标注录像及其元数据。可通过 `VISION_STUDIO_DATA_DIR` 指定另一数据目录。卸载程序不会要求清除个人导出；保留与清理这些用户文件由用户自行决定。

```bash
sudo apt remove vision-studio
```

## 本次功能与运行时

图片及批量图片、视频和摄像头输入，目标检测和单标签分类，PNG / JSON / CSV 导出，结果缩放和平移，模型库与运行记录。图片批量任务可逐张自动导出；视频与摄像头任务结束后导出最后一帧。

1.3.0 在灰度输入及单设备左右拼接画面选择的基础上，增加实际灰度预览与标注视频录制；导航保留原四页，追加「录制视频」和末尾的「更多」。运行示例与手动导出入口移至「更多」。ONNX 自动识别固定 1 / 3 输入通道；灰度统一使用一个均值，检测补边保持 114。摄像头与视频可使用完整画面、左目或右目，检测坐标和导出相对所选画面；保留设备默认分辨率，奇数宽度时右目多一列。图片始终完整处理。旧版默认彩色与完整画面设置继续兼容。

现代 Ultralytics、兼容旧版 YOLOv5 和标准 TorchScript `.pt` 也可使用 1 / 3 通道灰度模型；手工均值保持零，检测仍除以 255，灰度分类使用 Ultralytics 分类变换并统一 `mean=0`、`std=1`。通道与必要元数据约定见 `模型说明.md`。

视频或摄像头开始推理后可开始 / 结束录制，保存所选眼、实际灰度或彩色画面与检测标注。录像以 MJPEG AVI 和同名 JSON 保存，在「录制视频」页浏览和播放；图片批量任务不录制。灰度预览及 PNG 底图显示实际灰度，切回彩色恢复原色并清除旧检测，需要重新推理。

ONNX 使用 C++ / OpenCV DNN 4.5.4 CPU；`.pt` 使用常驻本地 Python / PyTorch CPU 进程。发行环境为 Python 3.10、PyTorch 2.9.1+cpu、Torchvision 0.24.1+cpu、Ultralytics 8.4.173、NumPy 2.2.6、opencv-python-headless 4.11.0.86。完整的 56 个随包 Python 发行版记录在 `licenses/PYTHON-DISTRIBUTIONS.json`，安装目录的 `requirements-pt.lock.txt` 是该包实际锁定清单。无 GUI OpenCV wheel 避免再引入另一套 Qt；原生界面使用 Qt 6.8.3。

支持标准 Ultralytics YOLOv8 / YOLO11 完整 `.pt` 检查点、兼容随附 YOLOv5 v7.0 网络源码的旧版完整检查点，以及带任务与类别元数据的兼容 TorchScript `.pt`。内置旧版权重来自 YOLOv5 **v6.0**。裸 `state_dict`、需额外自定义网络源码的检查点、分割、姿态及旋转框模型不在当前兼容范围；详见 `模型说明.md`。加载 `.pt` 时应使用自己训练或可信来源的检查点。

当前推理均为 CPU。未提供 CUDA / TensorRT 后端。摄像头硬件及其驱动需要在实际设备上验证；本次自动测试使用本地图像与短视频。

## 验证记录

核心回归用例通过真实 OpenCV forward 验证灰度亮度、C1 / C3 输入、统一均值、114 补边和通道错误；使用合成左右拼接视频与真实推理验证所选眼的内容、尺寸、坐标、奇数宽度和图片完整处理。本版完整执行结果及最终数量以随附的本版 CTest 日志为准。

PT 后端、UI 和正式 DEB 的最终统一检查结果，以本版发行目录的 `qa-report.json`、`install-qa.json`、`desktop-qa.json` 及对应 CTest 日志为准。摄像头硬件需要在实际设备上检查。上一级 `验证报告.md` 保留早期安装的历史证据，不能替代本版执行结果。源码完整性使用主文件 `SHA256SUMS` 与拆分源码 `SOURCE-SHA256SUMS` 检查。

## 开源交付

新编写的应用代码按 AGPL-3.0-only 发布。Qt 使用 LGPLv3 许可选项；YOLOv5 资源与源码保留 GPLv3，Ultralytics 与 YOLOv8 模型保留 AGPLv3。其他组件保持各自原始许可。完整正文、版权和通知保存在 `licenses/` 与 `copyright`，并随包安装。

发行目录提供 `vision-studio-1.3.0-complete-source.tar.xz`，内部包含 `vision-studio-1.3.0-sources.tar.xz` 与 `sources/` 下的对应上游源码归档。发布或转发此版本时，应将 DEB、完整源码包和校验清单一起提供。独立归档仍保留在发行目录，便于逐项验收。源码位置、重建步骤、Qt 替换接口见 `对应源码与重建.md`。
