# Vision Studio 1.1.0 发行说明

维护者：misaka_ning <1468549029@qq.com>。本次交付为本地 DEB 与配套源码文件，没有上传到公共仓库。

## 安装与启动

发行平台为 Ubuntu 22.04 amd64（x86_64），使用 C++17 / Qt 6.8.3。正式包包含 Qt 运行库、独立的 Python 3.10 CPU 环境、YOLOv8n / YOLOv5n 检查点及 ONNX 示例。安装后无需在线下载模型或 Python 依赖；APT 可能需要安装包声明的系统共享库。

```bash
sudo apt install ./vision-studio_1.1.0-1_amd64.deb
vision-studio
```

也可从应用菜单启动 Vision Studio。程序文件位于 `/opt/VisionStudio`，发行文档和许可位于 `/usr/share/doc/vision-studio`。首次体验可在工作台点击「运行示例」。完整操作见上一级目录的 `使用指南.md`。

设置、运行记录及默认导出位于 `${XDG_DATA_HOME:-$HOME/.local/share}/vision-studio`，其中 `preferences.ini` 保存设置，`history.json` 保存记录，`results/` 保存结果。可通过 `VISION_STUDIO_DATA_DIR` 指定另一数据目录。卸载程序不会要求清除个人导出；保留与清理这些用户文件由用户自行决定。

```bash
sudo apt remove vision-studio
```

## 本次功能与运行时

图片及批量图片、视频和摄像头输入，目标检测和单标签分类，PNG / JSON / CSV 导出，结果缩放和平移，模型库与运行记录。图片批量任务可逐张自动导出；视频与摄像头任务结束后导出最后一帧。

ONNX 使用 C++ / OpenCV DNN 4.5.4 CPU；`.pt` 使用常驻本地 Python / PyTorch CPU 进程。发行环境为 Python 3.10、PyTorch 2.9.1+cpu、Torchvision 0.24.1+cpu、Ultralytics 8.4.173、NumPy 2.2.6、opencv-python-headless 4.11.0.86。完整的 56 个随包 Python 发行版记录在 `licenses/PYTHON-DISTRIBUTIONS.json`，安装目录的 `requirements-pt.lock.txt` 是该包实际锁定清单。无 GUI OpenCV wheel 避免再引入另一套 Qt；原生界面使用 Qt 6.8.3。

支持标准 Ultralytics YOLOv8 / YOLO11 完整 `.pt` 检查点、兼容随附 YOLOv5 v7.0 网络源码的旧版完整检查点，以及带任务与类别元数据的兼容 TorchScript `.pt`。内置旧版权重来自 YOLOv5 **v6.0**。裸 `state_dict`、需额外自定义网络源码的检查点、分割、姿态及旋转框模型不在当前兼容范围；详见 `模型说明.md`。加载 `.pt` 时应使用自己训练或可信来源的检查点。

当前推理均为 CPU。未提供 CUDA / TensorRT 后端。摄像头硬件及其驱动需要在实际设备上验证；本次自动测试使用本地图像与短视频。

## 验证记录

发行用无 GUI OpenCV 环境执行的三套 CTest 全部通过：13 个核心功能用例、12 个 PT 后端功能用例、4 个 UI 功能用例；加上各组初始化和清理，共 35 个 QtTest 成功结果，0 失败、0 跳过。原始日志保存在 `CTest-2026-10-05.log`。测试覆盖真实 YOLO 权重、连续推理、旧版文件改名及邻近权重干扰、取消、超时、模型身份校验，以及真实 UI 导出。

正式 DEB 已检查 301 个 ELF 文件，未发现未解析的共享库；APT 安装模拟未要求删除现有系统包。解包后在只读应用目录、普通用户 UID 1000 下运行 ONNX、现代 `.pt` 与旧版 YOLOv5 `.pt`，三个模型均产生 5 个真实目标。

在网络隔离、宿主文件系统只读的私有命名空间中，UID 0 实际执行 dpkg 安装，UID 1000 从真实 `/opt/VisionStudio` 和命令入口离线运行 ONNX / PT，再执行卸载。安装、推理、卸载均成功，用户数据快照保留，宿主 dpkg 数据与桌面集成未改变。X11 实际工作台检测 5 个目标，PNG / JSON / CSV 导出以及 PNG / JPEG / WebP / TIFF 读写检查均通过。摄像头硬件不在这些检查范围内。

具体证据为发行目录的 `qa-report.json`、`install-qa.json`、`desktop-qa.json` 与 `ui-preview.png`；三套 CTest 原始日志随外部源码提供。上一级 `验证报告.md` 同时保留原家目录安装的验收证据。源码完整性检查使用主文件 `SHA256SUMS` 与拆分源码 `SOURCE-SHA256SUMS`。

## 开源交付

新编写的应用代码按 AGPL-3.0-only 发布。Qt 使用 LGPLv3 许可选项；YOLOv5 资源与源码保留 GPLv3，Ultralytics 与 YOLOv8 模型保留 AGPLv3。其他组件保持各自原始许可。完整正文、版权和通知保存在 `licenses/` 与 `copyright`，并随包安装。

发行目录提供 `vision-studio-1.1.0-complete-source.tar.xz`，内部包含 `vision-studio-1.1.0-sources.tar.xz` 与 `sources/` 下的对应上游源码归档。发布或转发此版本时，应将 DEB、完整源码包和校验清单一起提供。独立归档仍保留在发行目录，便于逐项验收。源码位置、重建步骤、Qt 替换接口见 `对应源码与重建.md`。
