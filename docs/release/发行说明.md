# Vision Studio 2.9.0

本版完善模型评估、实验分析与报告交付，继续使用 C++17／Qt 6.8.3、Fluent 深色界面和既有 CPU／NVIDIA GPU 后端，无新增运行依赖。验收范围、实际结果和限制以同版证据为准，未执行检查不声明通过。

## 主要变化

- 评估界面按五个内层页组织，补充 AP75、Wilson 95% 描述区间、FPPI、整图漏检率和两种不同口径的混淆矩阵。九类诊断图覆盖 PR、阈值表现、阴性图片误报率、TP／FP／FN、AP–IoU、FROC、检测混淆、图像有无目标混淆与场景对比。
- 完整展示 All、Small、Occluded、Blurred、No Ball、No difficulty 六类分组的 AP、工作点指标与错例入口。未审核场景保留未知状态；单图、子集和中断任务不提升为整集主 AP。
- 报告导出支持 PNG／SVG／PDF、可选 DPI、PR／AP／场景数值表和 LaTeX 表格行。复用已经保存的 GT／预测快照重新选择分析阈值、匹配 IoU 和扫描范围，生成独立新报告，保留原报告；数值分析无需原模型或数据集，图片叠加仍须原图存在且哈希一致。
- 支持只读导入既有 model-evaluation 脚本的完整评估快照，交叉检查清单、类别、框、分数和数量，保持模型原始类别 ID。来源运行时与推理参数如实保留；未知预处理／后端设置不补成可采用配置，导入报告及其后续重分析均禁止采用到检测工作台。
- 现代和旧版 PT 检测支持真实批量推理；ONNX／TorchScript 明确按单张执行并记录实际情况。可调候选采集下限、每图最大框数和 PT CPU 线程；阈值扫描复用固定 NMS 后的候选，不把图片循环宣称为模型 batch。
- 保留全局模型、数据集启动恢复、灰度 C1／C3、左右目视频／摄像头、录制、模型显示、YOLO YAML、转换、三种图片范围、停止与结果回看。个人设置、模型、运行记录、录像和历史报告不删除，已公开标签和旧发行文件不改写。

## 验收与兼容范围

本版[证据目录](https://github.com/misaka-ning/vision-studio/blob/v2.9.0/docs/releases/evidence/2.9.0/README.md)用于记录适用的 Qt／Python 回归、真实 CPU／CUDA、最终 DEB、安装、对应源码及本版专项检查。发布与使用判断以同版报告中的实际执行结果和限制为准；本说明不预先声明检查通过，也不沿用旧版通过数量、耗时或截图。

主 AP 仍指映射的一个目标类别，不是多类别总体 mAP。完整 Val 才提供部署工作点建议；Test、Train、单图、子集和中断结果按各自范围解释。COCO ID 32 是 sports ball，并非只识别足球。本版不新增训练、TensorRT、多模型自动实验队列、分类评估或视频在线 mAP。公开小集合、合成标注、重复图片调度检查和历史私有快照导入各有适用范围，不能替代足球模型能力或跨设备性能测试。Windows 已发布版仍为 2.1.0，不将 Windows 2.9.0 或物理摄像头列作本版已验收项目。

## 安装与对应源码

正式标签为 `v2.9.0`，Debian 包版本为 `2.9.0-1`，默认安装到 `/opt/VisionStudio`。正式发布后，Linux Release 提供三个手动附件：

- `vision-studio_2.9.0-1_amd64.deb`
- `vision-studio-2.9.0-complete-source.tar.xz`
- `SHA256SUMS`

下载后先校验再安装：

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.9.0-1_amd64.deb
```

升级前结束检测、评估、录像与模型转换，导出需要长期保留的临时结果并退出旧程序。升级保留个人资料与已准备的 GPU 环境。完整源码包提供应用源码、需要交付的原始上游源码、来源、许可与校验；GitHub 自动源码 ZIP／TAR 不能替代完整对应源码包。

远端标签、公开状态及三个附件的大小与 SHA256 全部核验成功后，再按规范保留本地最新两个正式发行版本 2.9.0 和 2.8.0，并逐版精确检查旧发行／独立构建副本。既有 Linux 核心附件、Windows 2.1.0 补充包与历史证据保持原样。
