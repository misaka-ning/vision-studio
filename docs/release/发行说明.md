# Vision Studio 2.0.0-beta.2

本版修复导入文件夹并完成批量检测后，切换回旧图片只能看到原图的问题。已完成图片的本轮识别结果可在队列中回看，恢复标注、目标表、指标和当前导出对象；零目标结果也可导出，未处理图片只显示原图。回看复用结果，不重新推理、追加运行记录或重复自动导出。

本轮缓存仅用于当前会话，清空队列、开始新任务、切换模型／预览模式／计算设备或关闭程序时释放。需要永久保留的完整图像与预测，仍应通过手动或自动导出保存。完整发布说明见仓库 `docs/releases/2.0.0-beta.2.md`。

保留 Beta.1 的 Fluent 界面：窗口、卡片和输入使用中性深色，蓝色 `#60CDFF` 强调操作、选择与焦点；左配置、中画布／队列、右结果表及模型三视图保持统一视觉。Fluent-Qt 仅作视觉参考，保留原 MIT 与来源，不引入其库或上游资产。

推理和数据约定沿用 1.6.0：CPU ONNX 使用 C++ OpenCV DNN，可选 NVIDIA GPU 使用 C++ ONNX Runtime CUDA；PT 三类模型使用常驻 Python 后端。Netron 结构图、层级树、参数表与全局选择缓存，灰度 C1／C3、左右目、标注录像和导出格式保留。GPU 配置使用原有独立用户环境、版本／SHA256 锁和真实 CUDA 自检，不修改驱动。

应用、标签与源码归档使用 `2.0.0-beta.2`，Debian 包使用 `2.0.0~beta.2-1`。GitHub Release 标记 Pre-release，不替换当前正式版 Latest；同版说明、完整源码、最终 DEB QA、三个远端资产 SHA256 与标签必须全部核验。

## 安装与证据

最终 Release 构建已通过全部 8 组 CTest（176.359 秒），零失败、零跳过；GPU 后端 10 项、录像 14 项与批量回看专项 3 个功能场景均通过。发布／清理安全 48 项、版本元数据 11 项测试通过。最终 DEB、隔离安装、包内 CUDA／CPU 与对应源码报告单独核验，见同版证据。

目标平台为 Ubuntu 22.04 LTS amd64，安装目录 `/opt/VisionStudio`；设置、模型、运行记录、导出和录像保存在个人数据目录。安装前校验同版附件：

```sh
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.0.0-beta.2-1_amd64.deb
vision-studio
```

预发布要求批量检测、队列回看、导出对象与缓存清理的回归，以及全部适用 QA，包括真实 CUDA 节点、PT CUDA、包内 ONNX／PT CUDA、CPU 回归、灰度 C1／C3、左右目与录像、隔离安装／卸载和对应源码核验。报告必须绑定本版最终 DEB SHA256；实际报告与原始日志保存到 `docs/releases/evidence/2.0.0-beta.2`，随源码提交，不作为额外附件。物理摄像头按真实设备验证。
