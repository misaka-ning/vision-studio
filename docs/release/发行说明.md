# Vision Studio 2.0.0

2.0 正式版的本轮开发改进参数防误改、文件夹停止响应、保存目录入口和模型库排序；保留 Fluent 风格的深色界面与批量检测结果回看。窗口、卡片和输入使用中性深色，蓝色 `#60CDFF` 强调操作、选择与焦点；左配置、中画布／队列、右结果表及模型三视图保持统一视觉。Fluent-Qt 仅作设计参考，保留原 MIT 与固定来源，不引入其库或上游资产。

## 本轮操作改进

- 输入尺寸、置信度和 NMS IoU 禁用鼠标滚轮改值，保留明确的输入和步进操作。
- 文件夹结果按后台保存完成节奏交付，临时缓存、标注绘制、自动 PNG／JSON／CSV 和历史写入在后台执行；停止不等待写入，避免结果积压和界面阻塞。已交付结果仍可回看，已接受写入收尾后可开始下一任务。
- 自动保存每张图片的选项下方增加「打开保存文件夹」按钮，指向实际自动导出位置。
- 模型库可拖动排序并在重启后保留；重排不改变当前全局模型，工作台和模型显示继续使用选中模型。

ONNX CPU 的当前 OpenCV forward 不能强制中断，会在本次调用结束后停止；工作线程推理和后台写入保持界面响应。CUDA 保留 ONNX Runtime 终止请求，PT 保留子进程取消。关闭窗口异步等待已接受写入及线程清理，不在主线程阻塞；停止耗时依具体模型和阶段而定。

## 结果与缓存

导入文件夹并完成检测后，可点击队列中的已完成图片回看检测框、类别、置信度、目标表和指标，并导出当前图片的结果；关闭自动导出仍可回看，零目标结果也可导出。回看复用本轮结果，不重复推理、追加运行记录或重复自动导出。文件夹导入和结果回看沿用 Beta.2 的基线行为。

本轮缓存仅用于当前会话，清空队列、更换来源、开始新任务、切换模型／预览模式／计算设备或关闭程序时释放。需要永久保留的完整图像与预测，应通过手动或自动导出保存。完整发布说明与本轮实际验收结果见仓库 `docs/releases/2.0.0.md` 和 `docs/releases/evidence/2.0.0/`。

## 推理与兼容范围

CPU ONNX 使用 C++ OpenCV DNN，可选 NVIDIA GPU 使用 C++ ONNX Runtime CUDA；PT 使用常驻 Python／PyTorch 后端，兼容现代 Ultralytics、YOLOv5 v7.0 完整检查点与标准 TorchScript。Netron 结构图、层级树、参数表共用模型库的全局选择和解析缓存。普通 PT 的静态包含关系不能表示完整 forward，查看完整运算连接建议使用导出的 ONNX。

保留彩色与灰度 C1／C3、单设备左右水平拼接画面的左目／右目选择、标注录像、手动与自动导出。TensorRT、AMD／Intel GPU、分割、姿态、旋转框、带内置 NMS 或多个运行时图像输入的 ONNX 不在当前支持范围；其他模型应核对 `docs/模型说明.md` 的具体约定。物理摄像头须按真实设备验证。

DEB 携带离线 CPU／Netron 环境，可选 GPU 环境由用户主动配置到个人数据目录，使用完整版本／SHA256 锁和真实 CUDA 自检，不修改显卡驱动，也不在 APT／DPKG 安装中下载 CUDA。首次准备 GPU 需要网络和足够空间，准备完成后可离线推理。

## 交付文件

应用、标签与源码归档使用正式 `2.0.0`，Debian 包版本为 `2.0.0-1`，标签为 `v2.0.0`。正式 GitHub Release 使用 `prerelease=false` 并更新 Latest。每版保留三个手动附件：

- `vision-studio_2.0.0-1_amd64.deb`
- `vision-studio-2.0.0-complete-source.tar.xz`
- `SHA256SUMS`

GitHub 另外自动显示 Source code ZIP／tar.gz。完整对应源码包包含应用拆分归档、`SOURCE-INVENTORY.json`、`SOURCE-SHA256SUMS`、15 份原始上游源码、依赖重建说明与许可通知；自动源码入口不能替代完整包。QA 报告和原始日志保存于仓库同版证据目录，不额外上传 Release。

## 安装与升级

目标平台为 Ubuntu 22.04 LTS amd64，安装目录 `/opt/VisionStudio`。应用代码采用 AGPL-3.0-only，第三方组件保留其原始许可。

```sh
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.0.0-1_amd64.deb
vision-studio
```

正式包版本高于 Beta.2 的 `2.0.0~beta.2-1`，可直接升级。升级前停止检测与录像，导出要永久保存的结果并退出旧程序；个人设置、模型、运行记录、导出、录像与已准备的 GPU 环境保留。临时回看缓存不跨程序重启保存。

## 验收与版本管理

发布需完成四项专项验证，包括滚轮不改值、批量停止时延及界面响应、保存目录正确、拖动顺序持久化且全局选择保持；再使用本版正式源码重新构建，并执行所有适用回归、实际 CPU／CUDA 模型、模型三视图和缓存、灰度 C1／C3、左右目与录像检查。最终 DEB 必须通过普通用户运行、隔离离线安装／卸载、包内 ONNX／PT CUDA／CPU 和对应源码核验；报告绑定本版最终 DEB SHA256，不以 Beta 报告替代正式包验收。逐项实际结果与原始日志随源码提交。

源码、标签、Release 状态与三个资产的大小／SHA256 全部核验后，本地保留 2.0.0 和 1.6.0 的发行及独立构建副本。旧 Beta 副本须逐版精确核验后单独清理，用户文件、共享 SDK／runtime 和工作树不清理。已公开标签、核心资产与原始归档不覆盖。
