# Vision Studio 2.5.0

本版改进数据集导入、大队列响应和工作区布局，继续使用 C++17／Qt 6.8.3、Fluent 深色界面与既有 CPU／NVIDIA GPU 后端，无新增运行依赖。验收范围、实测结果和限制以同版证据报告为准。

## 主要变化

- 数据集文件夹和 YAML 共用一个选择器，不再通过箭头先选导入类型。单击文件夹后确认导入，双击仍可继续浏览；现有 YAML／YML 文件可直接导入。非法路径与类型显示行内提示，不增加确认弹窗；根目录配置解析、失效路径只读迁移和失败后重试保持既有规则。
- 大队列按 GUI 事件循环分片建立，缩略图按可见项及邻近范围后台解码，选中原图及缓存叠加异步加载。快速换图、切换颜色、清空或更换来源后丢弃过期回调，避免旧图覆盖新选择。队列顺序、三种范围、GT、结果回看和所选图片导出继续保留，无固定 50 张上限。
- 数据集设置改为锚定按钮的深色悬浮卡片，类别映射、扫描参数与可选审核文件不占工作台布局。再次点击按钮、点击外部、按 Esc 或关闭按钮均可收起；调整窗口与切页安全关闭，忙时锁定，完整校验错误可滚动和复制。
- 工作台「图像预览」「评估与阈值」各占完整工作区：检测页保留参数、画布、队列和目标表，评估页使用完整空间查看指标、曲线、错例与报告。切页只改变查看位置，不改变任务模式或配置、不清空缓存、不重复推理；点击对应开始操作才执行检测或评估。
- 保留全局模型、灰度 C1／C3、左右目视频／摄像头、录制、模型显示、转换、持久评估及已采用配置。个人设置、模型、运行记录、录像和历史报告不删除；已公开标签与旧发行文件不改写。

## 验收与兼容范围

本版[证据目录](https://github.com/misaka-ning/vision-studio/blob/v2.5.0/docs/releases/evidence/2.5.0/README.md)保存适用 Qt／Python 回归、真实模型、最终 DEB、隔离安装、CPU／CUDA、数据集评估、对应源码和专项 UI 检查的实际记录。实测结果与适用限制以同版报告及原始日志为准，不复用旧版通过数量、耗时或截图作为本版验收。

后台加载与心跳测试验证任务分工和取消，不承诺固定帧率或跨机器速度。合成图片／标签验证调度与 UI，公开标注集验证导入和真实推理；二者均不等于足球专用能力测试。评估仍只针对所选目标类 AP，不提供多类总体 mAP、训练、分类评估或视频在线 mAP。COCO ID 32 仍为 sports ball。Windows 2.5.0 与物理摄像头不列为本版已验收项目。

## 安装与对应源码

正式标签为 `v2.5.0`，Debian 包版本为 `2.5.0-1`，默认安装到 `/opt/VisionStudio`。Linux Release 继续仅上传三个手动附件：

- `vision-studio_2.5.0-1_amd64.deb`
- `vision-studio-2.5.0-complete-source.tar.xz`
- `SHA256SUMS`

发布后先校验再安装：

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.5.0-1_amd64.deb
```

升级前结束检测、评估、录像与模型转换，导出需要长期保留的临时结果并退出旧程序。保留个人资料与已准备 GPU 环境。完整源码包提供实际应用源码及需交付的原始上游源码、来源、许可与校验；GitHub 自动源码 ZIP／TAR 不代替完整对应源码包。

远端标签、公开状态、三个附件大小与 SHA256 全部核验成功后，按规范保留本地 2.5.0 与 2.4.0，再逐版精确检查旧发行／独立构建副本。既有 Linux 核心附件、Windows 2.1.0 补充包与历史证据保持原样。
