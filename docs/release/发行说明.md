# Vision Studio 2.10.0

本版增加模型库单／多模型文件拖入，与导入按钮共用校验，继续使用 C++17／Qt 6.8.3、Fluent 深色界面和既有 CPU／NVIDIA GPU 后端，无新增运行依赖。验收范围、实际结果和限制以同版证据为准，未执行检查不声明通过。

## 主要变化

- 模型库页面、说明区域和列表可拖入一个或多个 ONNX／PT／TorchScript 本地模型；导入按钮支持多选，两种入口共用完整校验、规范路径去重及批量追加。
- 按拖入顺序记录新路径，复用已有条目并保留名称、备注、顺序与配置，仅最后一项全局选用；检测工作台、结构显示缓存及转换页继续共享该模型。
- 非法混合输入整批拒绝并行内说明；忙时不更换模型，不移动、复制、改名原文件。列表内部拖动仍用于排序，右键管理及跨重启保存保持。
- 沿用 PT 边缘零面积框过滤及 FP32 参数适配、CPU／CUDA、灰度 C1／C3、左右目、录像、模型显示与转换、数据集评估和阈值分析。既有预测、GT、报告和用户资料保持。

## 验收与兼容范围

本版[证据目录](https://github.com/misaka-ning/vision-studio/blob/v2.10.0/docs/releases/evidence/2.10.0/README.md)用于记录适用的 Qt／Python 回归、真实 CPU／CUDA、最终 DEB、安装、对应源码及本版专项检查。发布与使用判断以同版报告中的实际执行结果和限制为准；本说明不预先声明检查通过，也不沿用旧版通过数量、耗时或截图。

主 AP 仍指映射的一个目标类别，不是多类别总体 mAP。完整 Val 才提供部署工作点建议；Test、Train、单图、子集和中断结果按各自范围解释。COCO ID 32 是 sports ball，并非只识别足球。本版不新增训练、TensorRT、多模型自动实验队列、分类评估或视频在线 mAP。公开小集合、合成标注、重复图片调度检查和历史私有快照导入各有适用范围，不能替代足球模型能力或跨设备性能测试。Windows 已发布版为 2.9.1，不将 Windows 2.10.0 或物理摄像头列作本版已验收项目。

## 安装与对应源码

正式标签为 `v2.10.0`，Debian 包版本为 `2.10.0-1`，默认安装到 `/opt/VisionStudio`。正式发布后，Linux Release 提供三个手动附件：

- `vision-studio_2.10.0-1_amd64.deb`
- `vision-studio-2.10.0-complete-source.tar.xz`
- `SHA256SUMS`

下载后先校验再安装：

```bash
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.10.0-1_amd64.deb
```

升级前结束检测、评估、录像与模型转换，导出需要长期保留的临时结果并退出旧程序。升级保留个人资料与已准备的 GPU 环境。完整源码包提供应用源码、需要交付的原始上游源码、来源、许可与校验；GitHub 自动源码 ZIP／TAR 不能替代完整对应源码包。

远端标签、公开状态及三个附件的大小与 SHA256 全部核验成功后，再按规范保留本地最新两个正式发行版本 2.10.0 和 2.9.2，并逐版精确检查旧发行／独立构建副本。既有 Linux 核心附件、Windows 2.9.1／2.1.0 补充包与历史证据保持原样。
