# Vision Studio 2.0.0-beta.1

本版是桌面 UI 调整的预发布候选。8 组 CTest 和真实 NVIDIA GPU 回归已通过；最终 DEB 的安装、包内 CUDA／CPU、源码验收和远端发布仍待完成。不能沿用旧版报告声明本版通过。完整发布说明见仓库 `docs/releases/2.0.0-beta.1.md`。

窗口、卡片与输入采用 Fluent 风格中性深色，蓝色 `#60CDFF` 强调操作、选择与焦点；4 px 控件、8 px 卡片圆角，212 px 侧栏和 3 px 导航选中条。顶部横向放置四个输入入口，设备／GPU 编号／提示位于第二行；左配置、中画布／队列、右结果表及模型三视图统一深色视觉。现有原生 Qt 控件、信号连接和键盘行为保留。

推理和数据约定沿用 1.6.0：CPU ONNX 继续使用 C++ OpenCV DNN，可选 NVIDIA GPU 使用 C++ ONNX Runtime CUDA；PT 三类模型继续使用常驻 Python 后端。Netron 结构图、层级树、参数表与全局选择缓存保留，灰度 C1／C3、左右目、标注录制和结果导出约定保留。GPU 配置使用原有独立用户环境、版本／SHA256 锁和真实 CUDA 自检，不修改驱动。

应用、标签与源码归档使用 `2.0.0-beta.1`，Debian 包使用 `2.0.0~beta.1-1`。GitHub Release 标记 Pre-release，不替换当前正式版 Latest；同版说明、完整源码、最终 DEB QA、三个远端资产 SHA256 与标签必须全部核验。

发布／清理工具 48 项、元数据／包装 11 项、原 GPU 配置安全 21 项通过，共 80 项；Python 语法检查通过。Fluent-Qt 仅作视觉参考，保留原 MIT 与来源，不引入其库或上游资产；新 QSS、SVG 和通知按现有递归规则交付。这些检查不代替最终模型、安装与远端验收。

## 安装与证据

目标平台为 Ubuntu 22.04 LTS amd64，安装目录 `/opt/VisionStudio`；设置、模型、运行记录、导出和录像保存在个人数据目录。安装前校验同版附件：

```sh
sha256sum -c SHA256SUMS
sudo apt install ./vision-studio_2.0.0-beta.1-1_amd64.deb
vision-studio
```

预发布仍要求全部适用 QA，包括真实 CUDA 节点、PT CUDA、包内 ONNX／PT CUDA、CPU 回归、灰度 C1／C3、左右目与录像。报告必须绑定本版最终 DEB SHA256；实际报告与原始日志完成后保存到 `docs/releases/evidence/2.0.0-beta.1`，随源码提交，不作为额外附件。物理摄像头按真实设备验证。

默认清理只识别正式版本，保留当前正式版作为回退；其他旧副本只能逐版精确核验远端后清理。已发布标签、核心文件和原始归档不覆盖。
