## 核心与工作线程

`vision-core-tests` 已通过 13 个功能用例。QtTest 总计 15 项通过（包含初始化和清理）、0 失败、0 跳过。

| 验证范围 | 实际覆盖 |
| --- | --- |
| YOLOv8 解码 | 128 × 64 原图至 64 × 64 输入的 letterbox 坐标映射、越界裁剪、完全越界丢弃 |
| NMS | 同类重叠抑制、不同类别相同位置保留 |

| 分类 | logits softmax、已归一化概率保留、类别排序 |

## 直接 PyTorch 后端

`vision-pt-tests` 使用真正的本地 PyTorch 进程和官方检查点验证直接 `.pt` 推理。现代 YOLOv8n 连续处理原尺寸图片与不同尺寸的 RGBA 图片，自动读取 COCO 80 类并检出 person 和 bus；输出置信度、原图坐标与耗时均经过检查。

旧版 YOLOv5n 用例在隔离目录中放置所选 `yolov5n.pt`，同时放入名为 `yolov5nu.pt` 的现代模型作为干扰，再将原始旧版权重复制为 `best.pt`。两个所选文件均按真实架构识别为 YOLOv5，实际执行检测；原始 SHA-256 保持不变，目录没有新增文件。此用例覆盖框架按文件名替换检查点的回归，确保执行用户选中的本地模型。

| 验证范围 | 实际覆盖 |
| --- | --- |
| 原生检查点 | 官方 YOLOv8n 与 YOLOv5n 真实载入、元数据读取与检测 |
| 持续请求 | 同一后台实例处理连续图片，不同图像尺寸与 RGBA 输入 |
| TorchScript 分类 | 本地生成带任务/类别元数据的实际 TorchScript，检查自动任务、softmax 与 top-k |
| 错误路径 | 显式 Python 路径不存在、损坏检查点、裸 `state_dict` 缺少架构、不能使用的 ONNX 预处理覆盖 |
| 取消 | 等待模型初始化和等待推理响应时取消，均在 2 秒内返回并清除加载状态 |
| 协议 | 非法 JSON、格式正常但模型路径与所选文件不一致的 ready 响应均被拒绝 |
| 超时 | 100 ms 测试载入期限终止未就绪后台进程 |

模型用例使用真实权重；协议、取消和超时用例使用专门的本地 Python 协议进程，以可重复方式触发阻塞和错误。TorchScript 分类网络是验证元数据和概率处理的测试网络，不属于内置训练模型。

## 设备与范围

摄像头硬件连接、设备权限与具体视频编码的可用性需要在实际设备和文件上验证。自动测试使用 MJPG / AVI 覆盖本机视频处理路径。当前版本使用 CPU，没有测试或启用 CUDA / TensorRT。

模型兼容性仅适用于 README 记录的架构、输入和输出约定。每个用户导入的 ONNX 或 `.pt` 模型仍需实际执行一次，以确认算子、预处理和输出匹配。未对任意自定义 `.pt` 网络或只有权重字典的未知架构声明兼容。
