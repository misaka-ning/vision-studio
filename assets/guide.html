Vision Studio 使用指南

选用模型 → 检测预览 → 标注评估 → 分析阈值 → 应用配置。模型与数据在本机处理。

开始检测　数据集与恢复　范围与筛选　评估与阈值　模型显示　保存结果

01 / 选模型，开始检测

  1. 在「模型库」导入并点击选用可信的 ONNX、完整 PT 或兼容 TorchScript。全局模型决定工作台、模型显示和转换页默认来源。
  2. 在「检测工作台 → 图像预览」选择 YOLO 数据集、视频或摄像头；也可向预览区拖入数据集目录／YAML、一个视频或单张／多张图片。
  3. 核对任务、输入尺寸、训练预处理与类别，选择 CPU、自动或 NVIDIA GPU，调整置信度、NMS IoU 和图片检测范围，再点「开始检测」。
  4. 完成或停止后点队列图片回看。需永久保存时使用自动保存，或「更多 → 导出结果」。

ONNX 检测支持原始 YOLOv5 [1,N,5+C] 或 YOLOv8／YOLO11 [1,4+C,N]，应为 batch=1、FP32、不含 NMS。完整 PT 自动读取任务与类别，使用本地 PyTorch。裸 state_dict 不能单独重建网络。分类显示 top-5，不使用检测类别筛选或目标检测评估。分割、姿态、旋转框与未知端到端输出暂不支持。

02 / 导入数据集与临时图片

点「YOLO 数据集」或按 Ctrl+O，在同一个选择器导入根文件夹或 YAML／YML。单击目录后点「导入此文件夹」，双击继续浏览。目录需有明确的数据集配置；配置有歧义时直接选文件。默认 Val，只有 Train 的数据集应切换 Train 后重新检查。

标准检测标签每行是 class_id x_center y_center width height，坐标归一化，images 与 labels 对应。空标签是已标注无目标，缺标签不是无目标，不能直接评估。导入后台检查、分片建立队列，缩略图懒加载，没有 50 张上限。

预览支持数据集目录／配置、视频和图片拖入，不能混合类型。已有数据集时拖图片，可选「替换整个数据集」「临时加入」或默认「取消」。临时图片无 GT，只参与检测，不写回数据集，不计入评估或负样本，也不跨重启恢复。忙时不更换输入。

「数据集设置」打开悬浮卡片，类别映射、审核文件和高级扫描参数集中在此。再次点按钮、点击外部或按 Esc 可收起，不挤压画布。

启动时恢复上次数据集

完整成功导入后，原始路径、集合与可选审核文件原子保存在个人目录 dataset-session.json。「更多 → 启动时恢复上次数据集」默认开启，下次普通启动后台检查并恢复队列与 GT，不自动检测、评估或恢复旧预测。

关闭仅影响下次启动，当前数据与记录保留，成功手动导入仍记住路径。重新开启从下次启动生效，不立即载入；它不会设置系统开机自启。清空、视频／摄像头和历史报告不覆盖最后成功记录。路径失效或 JSON 损坏时行内说明，可手动重新导入。

03 / 检测范围、类别与结果回看

图片范围本次任务
检测当前集合（默认）从首张到末张，包含临时追加图片
从当前图片向后检测包含选中图片，处理到末尾
只检测当前图片仅处理所选图片

后两项须先选图。开始时固定范围与顺序，进度只统计本次任务；运行时锁定范围与输入。视频和摄像头不使用图片范围。输入尺寸、置信度与 NMS IoU 不接受滚轮改值，可直接输入或用步进按钮。

「停止运行」不再调度下一张，当前 CPU forward 需结束；界面继续响应，结果后台收尾。已完成图片（含零目标）可回看导出。范围外有效缓存保留；更换模型、配置、设备或类别筛选后不兼容缓存失效。普通缓存不跨重启。

「类别标签」只映射名称。「类别筛选」留空为全部，支持 32、0,2,32、中文逗号或空格并去重；按当前模型实际范围校验，非法 ID 行内阻止开始。保留原始 ID，预览、计数、导出与录像一致。COCO ID 32 是 sports ball，含多种运动球，不等于只识别足球。

04 / 用真实标注评估模型

「图像预览」看预测与 GT，「评估与阈值」看指标与曲线，切页不开始任务或改配置。评估需要正确标注，当前评估映射的一种目标类别，不是多类总体 mAP。

  1. 导入数据集，选用检测模型，等待实际类别就绪。
  2. 在「数据集设置」核对模型原始 ID → 数据集 ID。例如 32: sports ball → 0: football；映射只用于比较，不改模型或 GT。
  3. 先在预览确认 GT 对齐，再到评估页核对模型、尺寸、颜色、NMS 与设备。评估使用完整图像，不裁左右目。
  4. 高级参数设置 GT 匹配 IoU 和扫描起止／步长，选范围后「开始评估」。匹配 IoU 判断命中，NMS IoU 抑制重复框。

一次后台推理采集低分候选，阈值分析复用缓存。评估只含原标注集合，不含临时图片；临时项不可作后缀／单图评估。停止只统计已完成前缀，未评估图不计漏检。

指标口径
mAP50 / mAP50–95映射目标类在 IoU 0.50，以及 0.50～0.95 上的 AP
Precision / Recall / F1当前分析置信度与匹配 IoU 下的精确率、召回率和调和平均
无目标图片误报率有目标误报的确认无目标图片数 / 确认无目标图片总数

AP 使用低分候选，不随当前分析阈值变化；P／R／F1 与误报率随工作点变化。完整完成且超过一张的整个集合才显示主 AP；子集、单图和中断明确标记，不代表完整成绩。Train 看拟合，Test 用于固定配置后验证。

05 / 分析阈值，逐张查看错例

默认扫描 0.05～0.95、步长 0.01，共 91 点。点击曲线／表格或改「分析阈值」更新指标与错例，不重复推理；非扫描点吸附到最近工作点。

「查看错例」进入预览并定位首张，显示「错图／已评估／集合」及序号，用「上一张」「下一张」依次浏览。FP 或 FN（含负图误报）均计错图，一图多处错误只计一张；框数不等于错图数。可切换全部图片、误检、漏检、无目标图误报或全部错例。

完整 Val 可查看 F1 最大、最低 Precision 或最高误报率约束推荐，无可行点不自动放宽。浏览推荐不改配置；只有「采用检测配置」才将报告输入、预处理、NMS、设备、目标 ID 和选定阈值应用到工作台，历史成绩不变。

评估报告与预测快照保存在个人目录 evaluations/，从运行记录或模型库可重开。原图存在且哈希一致才能叠加，移动／改变会提示，不把旧预测画到新图。可打开报告、保存目录或导出完整原始报告。

2.9 诊断图表与场景分析

评估页分为总览、阈值明细、诊断图表、场景分析、报告与重分析。新增 AP75、Wilson 95% 区间、FPPI、负图平均误报框数、正图整图漏检率；定位矩阵与图像存在性矩阵分别回答框是否定位正确、图片是否出现目标预测。

六类场景为全部、小目标、遮挡、模糊、无目标、无困难。无目标由所选类别 GT 判断；困难和无困难组需审核 metadata，未知不当作无困难。组不足两张或任务不完整时主 AP 为 N/A；场景错例可连续浏览。

历史快照重新分析与论文输出

「导入脚本评估报告」可导入 model-evaluation 脚本的完整结果目录（status.json、metrics.json、inputs_manifest.json、predictions.jsonl），后台校验后保存新报告，不改原件。原始后端信息不足时仅分析，不能自动采用成检测配置，后续重分析继续保持该限制。

「报告与重分析」调整置信度、GT 匹配 IoU、扫描范围后点「重新分析」，校验保存的 GT／预测快照并生成独立报告，不执行推理、不读取原模型和原数据集，不覆盖来源。叠加预览仍需原图存在且哈希一致；低于原候选下限不能重算。

默认九类图输出 PNG／SVG／PDF、300 DPI，可选择格式及72～1200 DPI。另有 PR、AP–IoU、场景与负图误报 CSV 和 LaTeX 表格行。格式设置用于新评估或新分析；导出原始报告保留其图表，并另记当前分析选择。

评估高级参数可调候选下限、最大检测框数、PT 线程及 batch1～32。ONNX／TorchScript 固定单张执行并记录实际值；ONNX 线程使用自动。更换候选配置或模型仍须重新推理。

06 / 模型显示与转换

模型库选用后后台解析结构，进出页面或切模式复用缓存。结构图看连接，层级树看包含关系，参数表看张量元信息；树与表支持搜索和详情。PT 层级不代表完整 forward，参数表不等于可训练参数总量。ONNX 更适合完整运算图。

仅有支持的 YOLO 架构字典时显示「YOLO YAML」；ONNX 和不支持的模型隐藏该项。One Dark Pro 风格只读代码视图提供行号、语法高亮、搜索、复制与另存。[from, repeats, module, args] 来自文件保存的架构，不恢复原始注释／排版，不执行模型或猜模板；缩放配置不等于实际算子数。架构 YAML 不代替数据集 YAML。另存拒绝覆盖已有文件、符号链接或源模型。

模型库可拖排序，右键打开位置、编辑备注、更改显示名称或移除，不改磁盘权重。「模型转换」默认用全局模型，可将受支持的 PT 导出 ONNX／TorchScript，CPU FP32、batch=1、固定输入、不含 NMS，保留 C1／C3；已有输出拒绝覆盖。明确「加入模型库」才选用结果，不还原 ONNX 为可训练 PT。

07 / 颜色、GPU 与左右目

预处理应与训练一致。常见 YOLO 为 RGB、1/255 与零均值；ONNX 可调缩放／均值，PT 使用框架预处理。灰度 C1 输入一份亮度，C3 输入三份相同亮度，预览和导出同步变灰。灰度 ONNX 统一用灰度均值，RGB／BGR 与 G／B 均值不改变灰度；选灰度不会改变模型训练方式。

自动设备优先就绪 NVIDIA GPU，不可用时说明并用 CPU；显式 GPU 失败报错。实际执行以状态和结果字段为准。首次到「更多」检查并准备 GPU，联网约 4～5 GB，建议预留 20 GB，可取消、不修改驱动。CPU ONNX 用 OpenCV DNN，GPU ONNX 用 ONNX Runtime CUDA，PT 用本地 PyTorch。TensorRT、AMD／Intel GPU 暂不支持。

单设备水平左右拼接视频／摄像头可选完整、左目或右目，先裁再预处理。预览、坐标、导出与录像对应所选眼，JSON 另记源尺寸。图片始终用完整画面；此选项不提供双目测距。

08 / 保存结果、录像与个人数据

「更多 → 导出结果」或 Ctrl+E 保存所选图／帧的标注 PNG、JSON 和 CSV，零目标也能保存。「自动保存每张图片的结果」逐张保存本次范围；视频／摄像头结束只保存最后一帧，旁边「打开保存文件夹」进入实际目录。

视频／摄像头检测中「开始录制」，再次点「结束录制」。源结束、停止或退出也会收尾；待保存完成到「录制视频」播放、定位或导出。录像是标注 MJPEG AVI 与 JSON，只含处理帧、无音频；图片队列不录制。

设置、模型列表、导出、历史、录像、评估与 GPU 环境在用户目录，默认 ${XDG_DATA_HOME:-$HOME/.local/share}/vision-studio，可由 VISION_STUDIO_DATA_DIR 指定。程序不自动上传输入与预测。升级前结束任务、导出临时结果并退出旧程序，再校验安装；卸载不自动删除个人资料。
