# Fluent-Qt design reference

Vision Studio 2.0 studies the Fluent-Qt v1.9.2 dark visual language at commit `6dfe61e01dff88aa0669b19e7b4faa2d5400e30e`. The attached original MIT license and provenance record that reference.

Repository: https://github.com/calvinhxx/Fluent-Qt

Vision Studio retains its standard Qt widget classes, existing local fonts and existing icons. It does not link FluentQt or distribute its Inter fonts, Microsoft icon pack, Gallery, screenshots or other third-party assets. Its own theme and new checkmark SVG are application source under AGPL-3.0-only.
